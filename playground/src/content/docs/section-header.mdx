## Add

```sh
npx @ava-ui/apogee add section-header
```

Depends on `Eyebrow`, `Heading`, `Text`.

## Usage

```astro
---
import SectionHeader from '@/components/apogee/SectionHeader/SectionHeader.astro'
---
<section aria-labelledby="pricing-heading">
  <SectionHeader id="pricing-heading" eyebrow="Pricing" heading="Simple plans" align="center" />
</section>
```

## API

`@composable`. Any other native attribute passes through to the wrapper.

| Prop | Type | Default | Description |
|---|---|---|---|
| `eyebrow` | `string` | — | Small label above the heading. |
| `heading` | `string` | — | Required. |
| `description` | `string` | — | One or two sentences under the heading. |
| `headingLevel` | `1 \| 2 \| 3 \| 4` | `2` | Semantic level of the heading element. |
| `align` | `'start' \| 'center'` | `'start'` | Alignment; `center` also centres the block. |
| `background` | `'page' \| 'neutral-faded' \| 'primary-faded' \| 'primary' \| 'inverted'` | `'page'` | The surrounding section's background, so eyebrow and description colours stay readable. |
| `size` | `'medium' \| 'large'` | `'medium'` | `large` uses the display size (Hero). |
| `id` | `string` | — | Id on the heading for `aria-labelledby`. |
| `class` | `string` | — | Extra classes on the wrapper. |

## Accessibility

- The heading is a real `h1`–`h4`; keep the page's heading order and point the section's `aria-labelledby` at `id`.
- Colours per `background` keep AA in both themes; solid fills inherit the on-colour.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-primary` | Eyebrow on page and tinted backgrounds |
| `--foreground-neutral-faded` | Description on page and tinted backgrounds |
| `--on-primary`, `--on-inverted` | Everything on the solid fills (inherited) |

Layout primitive, so no content rules.
