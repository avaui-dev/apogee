## Add

```sh
npx @ava-ui/apogee add table-of-contents
```

No dependencies. Zero JS.

## Usage

Build the items from your headings (Astro's `render()` returns them):

```astro
---
import TableOfContents from '@/components/apogee/TableOfContents/TableOfContents.astro'
const { headings } = await render(entry)
const items = headings.filter((h) => h.depth === 2).map((h) => ({ label: h.text, href: `#${h.slug}` }))
---
<TableOfContents items={items} />
```

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `{ label, href, children? }[]` | — | Required. `children` nest one level. |
| `label` | `string` | `'Table of contents'` | The visible heading and the nav's name. |
| `current` | `string` | — | `href` of the section to mark as current (`aria-current="location"`). |
| `class` | `string` | — | Extra classes on the `<nav>`, merged last. |

## States

- **Current** — the matching link turns primary and bold.
- **Hover** — links darken.

## Accessibility

- A `<nav>` named by `label`; the visible heading repeats it for sighted readers (hidden from screen readers so it is not read twice).
- The current section carries `aria-current="location"`.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-primary` | Heading and the current link |
| `--foreground-neutral-faded` / `--foreground-neutral` | Links / hover |

## Do / Don't

- **Do** use it on pages long enough to scroll several screens.
- **Don't** list every heading; the second level is plenty.

## Content

- Use the headings' own words, so the link matches what the reader lands on.
