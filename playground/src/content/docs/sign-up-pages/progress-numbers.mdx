## Add

```sh
npx @ava-ui/apogee add sign-up/progress-numbers
```

This copies the page to `src/components/apogee/pages/sign-up/` with everything it uses: AuthShell, Button, FeaturedIcon, Input, PasswordChecklist, Steps. Render it from one of your routes, or use **Copy code** above.

## Accessibility

- The page heading is the `h1`; the fields carry visible labels and `autocomplete` hints (`new-password` for new passwords, so password managers offer to generate one).
- The steps are an ordered list; the current one is marked with `aria-current="step"`.
