## Add

```sh
npx @ava-ui/apogee add faq/simple-03
```

This copies the block to `src/components/apogee/blocks/faq/` with everything it uses: FeaturedIcon, Heading, Image, Link, Section, SectionHeader. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/faq-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
