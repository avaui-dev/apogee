## Add

```sh
npx @ava-ui/apogee add content-wrapper
```

No Apogee dependencies.

## Usage

```astro
---
import ContentWrapper from '@/components/apogee/ContentWrapper/ContentWrapper.astro'
---
<ContentWrapper>
  <p>Page content, one column.</p>
</ContentWrapper>
```

## Anatomy

- Default slot — the first (primary) column; always rendered.
- `secondary` slot — the second column; only rendered when `variant` is `columns` or `sticky`.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root element.

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'stack' \| 'columns' \| 'sticky'` | `'stack'` | `stack`: one column. `columns`: two even columns from `md` up. `sticky`: two columns; the second sticks as the first scrolls. |
| `reverse` | `boolean` | `false` | Shows the second column first (from `md` up). No effect on `stack`. |
| `gap` | `4 \| 6 \| 8 \| 10 \| 12` | `8` | Gap between columns (Tailwind spacing scale). |
| `class` | `string` | — | Extra classes, merged last. |

`reverse` flips which column shows first (visually, from `md` up); `gap` accepts
`4 | 6 | 8 | 10 | 12` — the default (`8`) is used above, tighten or loosen by
passing another value:

  <div slot="secondary">Shows first on desktop</div>
</ContentWrapper>`}>

    <div class="rounded-md border border-neutral p-4 text-sm">Shows second on desktop</div>
    <div class="rounded-md border border-neutral p-4 text-sm" slot="secondary">Shows first on desktop</div>
  </ContentWrapper>
</Preview>

## States

No interactive states — a plain layout container.

## Examples

A sidebar article layout: sticky secondary column, tight gap.

```astro
<ContentWrapper variant="sticky" gap={6}>
  <article>…</article>
  <aside slot="secondary">Table of contents, related links…</aside>
</ContentWrapper>
```

## Accessibility

Native semantics — no ARIA role, no focus management. DOM order is always
default slot first, `secondary` slot second; `reverse` only changes the
*visual* order (`md:order-2` / `md:order-1`), so tab and reading order follow
the DOM, not the visual layout.

## Tokens

No CSS custom properties — spacing uses Tailwind's fixed scale (`gap-4`…`gap-12`), not a themed token.
