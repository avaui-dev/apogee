## Add

```sh
npx @ava-ui/apogee add skeleton
```

No Apogee component dependencies.

## Usage

```astro
---
import Skeleton from '@/components/apogee/Skeleton/Skeleton.astro'
---
<Skeleton class="h-4 w-48" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other `<div>` attribute
passes through (spread after `aria-hidden="true"`, so it can be overridden if needed).

| Prop | Type | Default | Description |
|---|---|---|---|
| `class` | `string` | — | Sizes and shapes the placeholder (`h-4 w-48`, `size-12 rounded-full`, …). Merged last. |

Skeleton has no `variant` or `size` prop — every shape comes from `class`.

## States

- **Animated** — fades between its shade and a lighter one while content loads.
- **Reduced motion** — under `prefers-reduced-motion: reduce` the shimmer stops and the block stays still.

Match the shape you are standing in for: text lines stay rounded, avatars

## Accessibility

- `aria-hidden="true"` by default — hidden from assistive tech, since it carries
  no content of its own.
- Non-interactive: no role, no focus stop.
- To announce a loading state to screen readers, wrap the group in your own
  `role="status"` region with a visually-hidden label (or use `Spinner` with a
  `label`, which does this for you) — Skeleton itself stays silent.
- The block fades between `--background-neutral-faded` and a much lighter mix
  of it with the page colour; it stops under `prefers-reduced-motion`.

## Tokens

| Token | Used for |
|---|---|
| `--background-neutral-faded` | Placeholder fill |
| `--radius-md` | Default corner rounding (override via `class`, e.g. `rounded-full`) |

## Do / Don't

- **Do** match a Skeleton's shape and size to the content it replaces (same
  line-height, same avatar size) so layout doesn't jump when real content arrives.
- **Do** group Skeletons to mirror a card or list row, not one undifferentiated block.
- **Don't** leave a Skeleton on screen after data has loaded — swap it for the
  real content immediately.
- **Don't** use Skeleton for a single, whole-page loading state — use `Spinner`.

## Content

No text — Skeleton is decorative (`aria-hidden`) and carries no copy.
