## Add

```sh
npx @ava-ui/apogee add features/icons-and-image-03
```

This copies the block to `src/components/apogee/blocks/features/` with everything it uses: Container, FeaturedIcon, Heading, Section, SectionHeader, VideoPlayer. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/features-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The play button is named after the video; once it plays, the browser's own controls take over. The video has captions.
- Each integration icon is an image named after the tool.
