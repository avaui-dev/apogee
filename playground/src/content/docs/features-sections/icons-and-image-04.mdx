## Add

```sh
npx @ava-ui/apogee add features/icons-and-image-04
```

This copies the block to `src/components/apogee/blocks/features/` with everything it uses: Container, FeaturedIcon, Heading, Image, Section, SectionHeader. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Each integration icon is an image named after the tool.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
