## Add

```sh
npx @ava-ui/apogee add features/icon-cards-02
```

This copies the block to `src/components/apogee/blocks/features/` with everything it uses: FeaturedIcon, Heading, Link, Section. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Each integration icon is an image named after the tool.
- Each "Learn more" link names its feature for screen readers.
