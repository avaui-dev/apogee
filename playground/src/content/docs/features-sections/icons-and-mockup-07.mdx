## Add

```sh
npx @ava-ui/apogee add features/icons-and-mockup-07
```

This copies the block to `src/components/apogee/blocks/features/` with everything it uses: FeaturedIcon, Heading, Link, PaymentCard, Section, SectionHeader. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/features-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Each payment card is one image, named by its last four digits.
- Each integration icon is an image named after the tool.
- Each "Learn more" link names its feature for screen readers.
