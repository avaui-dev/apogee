## Add

```sh
npx @ava-ui/apogee add features/tabs-mockup-09
```

This copies the block to `src/components/apogee/blocks/features/` with everything it uses: DeviceFrame, Section, SectionHeader, Tabs. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/features-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The feature tabs are a tab list: arrow keys move between them, each tab is named by its title and described by its line, and without JS every panel shows.
