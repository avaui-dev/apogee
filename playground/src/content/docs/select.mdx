## Add

```sh
npx @ava-ui/apogee add select
```

Pulls in `Field`. Uses `@lucide/astro` for the chevron.

## Usage

```astro
---
import Select from '@/components/apogee/Select/Select.astro'
---
<Select label="Country" name="country">
  <option value="us">United States</option>
  <option value="ca">Canada</option>
</Select>
```

## Anatomy

- **Field** — the `Field` wrapper: label, hint/error text.
- **`<select>`** — the native control; pass `<option>`s (and `<optgroup>`s)
  in the default slot.
- **Chevron** — a decorative `ChevronDown`, `aria-hidden`, positioned over
  the select.

## API

`@composable` — exposed to Content Editors in AVA. Any other native
`<select>` attribute (e.g. `multiple`, `disabled`, `name`) passes through to
the `<select>` itself.

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated | Ties the `Field` label to the `<select>`. |
| `label` | `string` | — | Field label. |
| `hint` | `string` | — | Helper text below the control (hidden when `error` is set). |
| `error` | `string` | — | Error text; sets `aria-invalid` and switches the border to `--danger`. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size. |
| `required` | `boolean` | `false` | Marks the field required (native `required` + a visible `*` on the label). |
| `class` | `string` | — | Extra classes on the `Field` wrapper. |

## States

- **Hover / focus** — a visible `focus-visible` ring (`--ring`).
- **Disabled** — dimmed, `cursor-not-allowed`. Pass the native `disabled`
  attribute.
- **Error** — `aria-invalid="true"`, border switches to `--danger`, `Field`
  shows the error text with `role="alert"`.
- **Required** — the label shows a `*`.

## Accessibility

- Real `<select>` — full native keyboard (type-ahead, arrow keys) and mobile
  picker support for free.
- `label` renders a real `<label for>` via `Field`.
- `hint` / `error` are wired to the control through `aria-describedby`;
  `error` also sets `aria-invalid` and announces via `role="alert"`.
- The chevron is purely decorative (`aria-hidden="true"`) — it never carries
  meaning on its own.

## Tokens

| Token | Used for |
|---|---|
| `--border` | Control border |
| `--background` | Control fill |
| `--foreground` | Selected value text |
| `--muted-foreground` | Chevron icon |
| `--ring` | Focus ring |
| `--danger` | Error border (`aria-invalid`) + `Field`'s error text |

## Do / Don't

- **Do** use Select for 6+ options, or when the native mobile picker UX is
  wanted.
- **Do** give the first `<option>` a clear placeholder ("Select a country")
  when nothing should be pre-selected.
- **Don't** use Select for 2–5 always-visible options — `SegmentedControl`
  or `Radio` shows every choice at once.
- **Don't** style away the native chevron/appearance beyond what's already
  handled — it breaks the platform picker affordance.

## Content

- `label` is a short noun naming the field ("Country", not "Select your
  country").
- `hint` is one short clause, no ending period unless it's a full sentence.
- `error` states the problem and, where possible, the fix ("Choose a
  country").
