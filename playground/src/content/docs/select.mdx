## Add

```sh
npx @ava-ui/apogee add select
```

Pulls in `Field` and `utils`. Uses `@lucide/astro` for the chevron and the
checkmark.

## Usage

```astro
---
import Select from '@/components/apogee/Select/Select.astro'
---
<Select label="Country" name="country">
  <option value="us">United States</option>
  <option value="ca">Canada</option>
</Select>

<Select label="Plan" name="plan" placeholder="Pick a plan" options={[
  { value: 'free', label: 'Free', description: 'For trying things out' },
  { value: 'pro', label: 'Pro', description: 'For teams' },
]} />
```

## Anatomy

- **Field** — the `Field` wrapper: label, hint/error text.
- **`<select>`** — the native control; pass `<option>`s (and `<optgroup>`s)
  in the default slot. With `options` it is generated from the array and
  hidden while JS runs, but it is still the form control.
- **Trigger** (custom mode) — a field-styled `<button popovertarget>` showing
  the chosen label or the placeholder.
- **Listbox** (custom mode) — a `role="listbox"` popover anchored under the
  trigger, as wide as it, scrolling past 15rem.
- **Start / end** — `start` slot icon inside the control; `end` slot replaces
  the decorative chevron.

## API

`@composable` — exposed to Content Editors in AVA. Any other native
`<select>` attribute (e.g. `name`, `autocomplete`) passes through to the
`<select>` itself.

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated | Ties the `Field` label to the `<select>`. |
| `label` | `string` | — | Field label. |
| `hint` | `string` | — | Helper text below the control (hidden when `error` is set). |
| `error` | `string` | — | Error text; sets `aria-invalid` and switches the border to the critical colour. |
| `options` | `{ value, label, description?, disabled? }[]` | — | Renders the custom listbox (JS) over a generated native `<select>`. |
| `placeholder` | `string` | — | Empty first choice; shown faded until a value is picked. Disabled when `required`. |
| `value` | `string \| string[]` | — | Initial value(s). `selected` on an `<option>` works too. |
| `multiple` | `boolean` | `false` | Multi-select: native listbox, or checkmarks in the custom listbox. |
| `disabled` | `boolean` | `false` | Disables the control (and the custom trigger). |
| `size` | `'small' \| 'medium' \| 'large' \| 'xlarge'` | `'medium'` | Height: 28 / 36 / 48 / 56px. |
| `variant` | `'outline' \| 'faded' \| 'ghost' \| 'headless'` | `'outline'` | The box style: bordered, tinted, bare, or no box at all. |
| `hasError` | `boolean` | `false` | Marks the field invalid (`aria-invalid`, critical border) without an `error` message. |
| `required` | `boolean` | `false` | Marks the field required (native `required` + a visible `*` on the label). |
| `class` | `string` | — | Extra classes on the `Field` wrapper. |

Slots: `start` (icon inside the control), `end` (replaces the chevron).

## States

- **Hover / focus** — a visible `focus-visible` ring (`--border-primary`).
- **Disabled** — dimmed, `cursor-not-allowed`.
- **Error** — `aria-invalid="true"`, border switches to the critical colour,
  `Field` shows the error text with `role="alert"`.
- **Required** — the label shows a `*`.

## Accessibility

- Native mode: a real `<select>` — full native keyboard (type-ahead, arrow
  keys) and mobile picker support for free.
- Custom mode: a `<button aria-haspopup="listbox">` labelled by the field
  label and the shown value, and a `role="listbox"` of `role="option"`s with
  `aria-selected` (and `aria-multiselectable` when `multiple`). Opening
  focuses the chosen option; arrows and `Home` / `End` move, typing jumps,
  `Enter` / `Space` choose, `Escape` and outside click close (native light
  dismiss) and focus returns to the trigger. Clicking the label focuses the
  trigger. A `required` field that submits empty focuses the trigger, marks
  it `aria-invalid` and shows the browser's message as a `role="alert"`.
- `label` renders a real `<label for>` via `Field`.
- `hint` / `error` are wired to the control through `aria-describedby`;
  `error` also sets `aria-invalid` and announces via `role="alert"`.
- The chevron and checkmark are decorative (`aria-hidden="true"`).

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Control and listbox border |
| `--background-page` | Control fill |
| `--background-elevation-overlay` | Listbox background |
| `--background-neutral-faded` | Selected option fill |
| `--background-neutral-faded-highlighted` | Option hover / focus |
| `--foreground-neutral` | Selected value and option text |
| `--foreground-neutral-faded` | Chevron, placeholder, descriptions |
| `--foreground-disabled` | Disabled options |
| `--border-primary` | Focus ring |
| `--foreground-critical` | Error border (`aria-invalid`) + `Field`'s error text |

## Do / Don't

- **Do** use the native mode by default — the platform picker is the best
  one on phones.
- **Do** reach for `options` when choices need a description, an icon-sized
  layout or a consistent look across platforms.
- **Do** set a `placeholder` when nothing should be pre-selected.
- **Don't** use Select for 2–5 always-visible options — `SegmentedControl`
  or `Radio` shows every choice at once.

## Content

- `label` is a short noun naming the field ("Country", not "Select your
  country").
- `hint` is one short clause, no ending period unless it's a full sentence.
- `error` states the problem and, where possible, the fix ("Choose a
  country").
