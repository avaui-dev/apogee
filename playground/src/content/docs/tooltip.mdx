  Opens the bubble in the top layer with hover intent (500 ms on first hover,
  instant for neighbours), opens on focus at once, closes on Escape, ignores
  touch pointers, and moves `aria-describedby` onto the focusable trigger.

## Add

```sh
npx @ava-ui/apogee add tooltip
```

Depends on `utils` (anchored-panel helper, `island`). No icons.

## Usage

```astro
---
import Tooltip from '@/components/apogee/Tooltip/Tooltip.astro'
import Button from '@/components/apogee/Button/Button.astro'
---
<Tooltip text="Copy to clipboard" placement="bottom">
  <Button variant="outline" color="neutral">Copy</Button>
</Tooltip>
```

## Anatomy

- **Trigger** — whatever you put in the default slot. Make it focusable (a
  button or link) so keyboard users get the hint too; the island moves
  `aria-describedby` onto it.
- **Bubble** — a `role="tooltip"` `popover="manual"` span anchored to the
  trigger, in the top layer.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root wrapper `<span>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `text` | `string` | — | The hint. Wraps at 20rem. An empty string renders the slot alone, no bubble. |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'start' \| 'start-top' \| 'start-bottom' \| 'end' \| 'end-top' \| 'end-bottom'` | `'top'` | Side and alignment; flips when out of room. `start`/`end` mirror in RTL. |
| `panelClass` | `string` | — | Extra classes on the bubble. |
| `class` | `string` | — | Extra classes on the root wrapper. |

already has, so a control keeps its other descriptions.

## Long text and clipping

Text wraps at 20rem. The bubble is in the top layer, so an `overflow: hidden`
ancestor cannot cut it off.

## States

- **Hidden** (default) — the popover is closed.
- **Shown** — after 500 ms of hover (instantly when a neighbouring tooltip
  closed within the last 500 ms), or at once on focus; fades and scales in
  (`--duration-fast`, `--ease-standard`).
- **Closing** — 150 ms after the pointer leaves, at once on blur or Escape.

## Examples

An icon-only button is the classic case: the visible label is the tooltip,
the accessible name is `aria-label`.

```astro
<Tooltip text="Settings">
  <Button variant="ghost" color="neutral" iconOnly aria-label="Settings"><Settings /></Button>
</Tooltip>
```

## Accessibility

- The bubble has `role="tooltip"`; the focusable trigger points at it with
  `aria-describedby`, so screen readers read the hint after the trigger's
  name (hidden popover content still counts as a description).
- Appears on keyboard focus, not only hover. Put a focusable element in the
  slot or keyboard users never see it.
- `Esc` dismisses it (WCAG 1.4.13).
- The hint is supplementary. Never put the only label of a control in a
  tooltip; give the control an accessible name of its own.
- Touch pointers never open it: a tap goes to the control, not the hint.
- The fade respects `prefers-reduced-motion`.

## Tokens

| Token | Used for |
|---|---|
| `--background-inverted` | Bubble background |
| `--on-inverted` | Bubble text |
| `--radius-md` | Corner radius |
| `--duration-fast` / `--ease-standard` | Fade transition |

## Do / Don't

- **Do** use it for a two-to-five-word hint on icon buttons and truncated
  labels.
- **Do** keep the trigger focusable.
- **Don't** put links, buttons or formatted text in it; the bubble is plain
  text and cannot be hovered.
- **Don't** rely on it on touch screens; use visible text or a Popover for
  anything essential.

## Content

- Sentence case, no ending period: "Copy to clipboard", not "Copy to
  clipboard."
- Name the action or the outcome, not the control: "Opens in a new tab"
  rather than "Link".
