<JsNote fallback="The menu opens and closes natively (popovertarget), including Escape and outside click. Without JS there is no arrow-key navigation, items don't close the menu on activation, and submenus open on click only.">
  Adds the menu keyboard pattern (ArrowDown on the trigger opens and focuses
  the first item; arrows, Home and End move; ArrowRight / ArrowLeft open and
  close submenus), closes the whole menu when an item is activated, opens
  submenus on hover, and dispatches `apogee:dropdown-open` / `-close`.
</JsNote>

## Add

```sh
npx @ava-ui/apogee add dropdown
```

Uses `@lucide/astro` (`ChevronDown`, `ChevronRight`) and `utils`. Ships
`DropdownItem.astro`, `DropdownSection.astro` and `DropdownSub.astro` in the
same folder.

## Usage

```astro
---
import Dropdown from '@/components/apogee/Dropdown/Dropdown.astro'
import DropdownItem from '@/components/apogee/Dropdown/DropdownItem.astro'
---
<Dropdown label="Options" placement="bottom-end">
  <DropdownItem href="/edit">Edit</DropdownItem>
  <DropdownItem color="critical">Delete</DropdownItem>
</Dropdown>
```

## Anatomy

- **Trigger** — a `<button popovertarget>` showing `label` and a chevron that
  rotates while open. Or your own element in the `anchor` slot: give it
  `popovertarget` (the menu `id`) and `aria-haspopup="menu"`.
- **Menu** — the `role="menu"` popover, anchored to the trigger; default slot.
  Fill it with `DropdownItem`s (`role="menuitem"`), `DropdownSection`s
  (`role="group"`) and `DropdownSub`s (an item that opens a nested menu).

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Trigger text and the menu's accessible name. |
| `id` | `string` | auto-generated | Menu id. Set it when an `anchor` element needs `popovertarget`. |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'start' \| 'start-top' \| 'start-bottom' \| 'end' \| 'end-top' \| 'end-bottom'` | `'bottom-start'` | Side and alignment; flips when out of room. See [Popover](/docs/popover#placement) for all twelve. |
| `width` | `'trigger' \| string` | — | `'trigger'` matches the trigger's width; otherwise any CSS length. |
| `maxHeight` | `string` | — | Caps the menu height; items scroll past it. |
| `class` | `string` | — | Extra classes on the root `<div>`, merged last. |

### `DropdownItem` props

A link when `href` is set, otherwise a `<button>`. `@composable`. Slots:
`start` (icon), default (label), `end` (shortcut or badge).

| Prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | — | Renders an `<a>` instead of a `<button>`. |
| `color` | `'neutral' \| 'primary' \| 'critical'` | `'neutral'` | Text and hover tint. |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Padding, text and icon size. |
| `selected` | `boolean` | `false` | The chosen item: `aria-current="true"` and a faded fill (`aria-checked` with a checkbox or radio indicator). |
| `indicator` | `'none' \| 'check' \| 'checkbox' \| 'radio'` | `'none'` | A leading selection mark. The column stays reserved when unselected so labels align; `checkbox` / `radio` switch the role to `menuitemcheckbox` / `menuitemradio`. |
| `disabled` | `boolean` | `false` | Native `disabled` on a button; `aria-disabled` + `tabindex="-1"` on a link. |
| `class` | `string` | — | Extra classes, merged last. |

### `DropdownSection` props

A `role="group"` with an optional label and a rule above it when it is not first.

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Group heading (`aria-labelledby`). |

### `DropdownSub` props

An item that opens a nested menu beside it. Slots: `start` (icon), default (items).

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Item text and the nested menu's accessible name. |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Matches the items around it. |
| `placement` | placement | `'end-top'` | Where the nested menu opens. |

## States

- **Closed / open** — the native popover toggle; the chevron rotates 180°
  while open.
- **Out of room** — the menu flips to the opposite side, no JS.
- **Hover / focus** — the trigger tints on hover; keyboard focus shows a
  visible ring. Items tint on hover and on keyboard focus.
- **No JS** — see the JsNote above.

## Events

The root `<div>` dispatches `apogee:dropdown-open` and `apogee:dropdown-close`
(bubbling) alongside the native `toggle` event on the menu. Activating an
item closes the menu, nested menus included.

## Accessibility

| Key | Action |
|---|---|
| `Enter` `Space` | On the trigger, toggle the menu; on an item, activate it and close the menu. |
| `↓` | On the closed trigger, opens the menu and focuses the first item. |
| `↓` `↑` | Move between items, wrapping at the ends. |
| `Home` `End` | First / last item. |
| `→` | On a submenu item, opens the submenu and focuses its first item (`←` under `dir="rtl"`). |
| `←` | Inside a submenu, closes it and returns focus to its item (`→` under `dir="rtl"`). |
| `Esc` | Closes the open menu or submenu and returns focus to its trigger. |

- The menu has `role="menu"` and takes `label` as its accessible name;
  `DropdownItem`s carry `role="menuitem"`; sections are `role="group"`.
- The trigger is a `<button popovertarget>` with `aria-haspopup="menu"`;
  the browser sets `aria-expanded`. Clicking outside closes the menu (native).
- A disabled link item keeps its text but is `aria-disabled` and out of the
  tab order.
- **No JS** — the menu still opens, closes and light-dismisses; items are
  reachable with `Tab` in document order.

## Do / Don't

- **Do** keep the trigger `label` short — it's the only cue for what the menu
  holds.
- **Do** order items by frequency of use, with destructive actions last, in
  their own section and `color="critical"`.
- **Don't** pack more than a handful of items in one menu — use a full page or
  `Combobox` / `CommandPalette` for long lists.
- **Don't** nest more than one level of `DropdownSub`.

## Content

- Item labels are short verbs or verb phrases ("Edit", "Duplicate", "Delete"),
  sentence case, no ending punctuation.
- The trigger `label` names what the menu contains, not a bare "Menu" or
  "Options" when a more specific noun fits.
