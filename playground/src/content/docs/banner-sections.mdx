Each example is a block built on the [Banner](/docs/sections/banner) section: a
floating card or a full-width bar, on a neutral fill or the brand colour, with
an icon, actions or a [Countdown](/docs/countdown). The close button removes
the banner.

## Copy is props

Every block in this family takes the same content props (`BannerContent` in
`sections/_shared/banner.ts`), with its sample copy as the defaults. A block
ignores the props it has no place for, so you can swap one block for another and
keep the copy. The [Banner](/docs/sections/banner) section takes the same names for the props they share.

- `heading`: The one-line message. Asterisks are dropped; banner blocks have no accent style.
- `description`: The quieter line. In blocks with a link, *asterisks* mark the linked words; other blocks drop them.
- `linkHref`: Where the *starred* words in `description` link to; `null` leaves them as plain text.
- `primaryAction`: The one link button.
- `submitLabel`: The email form's button.
- `closeLabel`: The close button's accessible name.

- Pass `null` to hide an optional part, such as `description={null}`.
- Some blocks add props of their own; the top of each block's file lists them.
