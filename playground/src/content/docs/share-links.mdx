## Add

```sh
npx @ava-ui/apogee add share-links
```

Pulls in Button. The share sheet is the browser's own (every app the reader has), so there is no list of networks to keep up to date.

## Usage

```astro
---
import ShareLinks from '@/components/apogee/ShareLinks/ShareLinks.astro'
---
<ShareLinks title={post.title} />
```

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `url` | `string` | the current page | The address to share. |
| `title` | `string` | the page title | Passed to the share sheet and used as the email subject. |
| `copyLabel` | `string` | `'Copy link'` | |
| `copiedLabel` | `string` | `'Copied'` | Announced to screen readers after a copy. |
| `shareLabel` | `string` | `'Share'` | |
| `emailLabel` | `string` | `'Email'` | |
| `iconOnly` | `boolean` | `false` | Square icon buttons, named by their labels. |
| `size` | `'small' \| 'medium'` | `'medium'` | |
| `class` | `string` | — | Extra classes on the root, merged last. |

## States

- **Copied** — the link icon turns into a tick for two seconds and "Copied" is announced.
- **No share sheet** — the Share button stays hidden where the browser has none (most desktops).

## Accessibility

- Every button has a name, including `iconOnly` ones.
- The copy result is announced through a polite status region.

## Tokens

Reads the outline Button tokens.

## Do / Don't

- **Do** put it once, at the end of the article (or in a sticky sidebar).
- **Don't** add a row of network logos the reader may not use; the share sheet already lists theirs.

## Content

- "Copy link" says what it does; avoid "Share URL".
