## Add

```sh
npx @ava-ui/apogee add avatar-group
```

Pulls in `Avatar`.

## Usage

```astro
---
import AvatarGroup from '@/components/apogee/AvatarGroup/AvatarGroup.astro'
---
<AvatarGroup items={[{ name: 'Jordan Lee' }, { name: 'Priya Nair' }]} max={5} />
```

## Anatomy

- **`items` mode** — pass an `items` array; AvatarGroup renders an `Avatar` per
  entry (each gets the group's `size`) plus a **+N overflow chip** when `items.length > max`.
- **Manual mode** — omit `items` and drop `<Avatar>` children into the default
  slot instead; you control each avatar's props (including its own `size`). The
  overlap (`-space-x-2`) and ring (`ring-2 ring-page`) styling apply either way.

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<div>`
attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `{ src?: string; name?: string; alt?: string }[]` | — | Renders one `Avatar` per entry. Omit to use the default slot instead. |
| `max` | `number` | — | Show at most this many `items`, then a `+N` chip. Omit to show all. Ignored in manual (slot) mode. |
| `size` | `'xsmall' \| 'small' \| 'medium' \| 'large' \| 'xlarge'` | `'medium'` | Size applied to each generated `Avatar` and to the overflow chip. Doesn't affect manually slotted avatars — set their own `size`. |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

- Each `Avatar` carries its own accessible name (image `alt` or the initials
  fallback's `aria-label`) — see [Avatar](/avatar).
- The `+N` overflow chip is plain visible text (e.g. "+3"), not a control — it's
  not focusable and doesn't disclose the hidden names. If the overflow count
  needs to be actionable (e.g. open a full list), wrap the group in a `<button>`
  yourself; AvatarGroup doesn't do this.

## Tokens

| Token | Used for |
|---|---|
| `--background-page` | Ring color separating overlapping avatars (`ring-2 ring-page`) |
| `--background-neutral` | Overflow chip background |
| `--foreground-neutral` | Overflow chip text |

## Do / Don't

- **Do** set `max` for groups that could grow unbounded (team members, watchers).
- **Do** keep `size` consistent within a group.
- **Don't** mix `items` and slotted children — `items` (when set) takes over the default slot entirely.
- **Don't** expect the `+N` chip to be interactive — it's static text.
