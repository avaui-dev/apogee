## Add

```sh
npx @ava-ui/apogee add stat
```

No Apogee component dependencies. Depends on `@lucide/astro` for the arrows.

## Usage

```astro
---
import Stat from '@/components/apogee/Stat/Stat.astro'
---
<Stat label="Revenue" value="$48,900" change="+12%" trend="up" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | The metric's name. |
| `value` | `string` | — | The metric's value, rendered large and bold. Not formatted — bring your own currency/percent formatting. |
| `change` | `string` | — | Optional change indicator text, e.g. `"+12%"`. |
| `trend` | `'up' \| 'down'` | `'up'` | Colours the change and picks the arrow direction. |
| `changeStyle` | `'simple' \| 'trend' \| 'modern'` | `'trend'` | A plain arrow, a trend line, or a bordered pill where only the arrow is coloured. |
| `comparison` | `string` | — | Text after the change, e.g. `"vs last month"`. |
| `size` | `'medium' \| 'large'` | `'medium'` | Value size. |
| `class` | `string` | — | Extra classes, merged last. |

Slot `start` takes a FeaturedIcon beside the stack.

Static display — Stat renders plain text and an icon, no hover, focus,
disabled, or loading state applies.

## Accessibility

- Label, value, and change render as plain text in DOM order — a screen
  reader announces all three, not just the icon.
- The trend is conveyed by the `change` text itself (`"+12%"` / `"-4%"`), not
  color alone; the arrow icon is `aria-hidden`.
- Native semantics, no extra ARIA needed.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-neutral-faded` | Label color |
| `--foreground-neutral` | Value color |
| `--foreground-positive` | Positive change text + icon (default when `trend` is omitted) |
| `--foreground-critical` | Negative change text + icon (`trend="down"`) |

## Do / Don't

- **Do** keep `label` to one to three words so it reads at a glance.
- **Do** pass `trend="down"` together with a negative `change` — the color
  and the number should agree.
- **Don't** vary the `value` format (currency symbol, decimal places) across
  stats shown together — keep a group consistent.
- **Don't** use Stat for a number with no context — always give it a `label`.

## Content

- `value` is shown exactly as passed — format currency, percentages, and
  separators before handing it to the component.
- `change` reads best as a signed delta or percentage (`"+12%"`, `"-4%"`,
  `"+128"`).
- Labels are short nouns, sentence case, no ending punctuation.
