## Anatomy

- **Menubar root** — `role="menubar"`, a row of top-level menus.
- **Menu** — one `<details>` per top-level entry (`menus[i]`).
  - **Summary (trigger)** — `role="menuitem"`, `aria-haspopup="true"`; the
    visible label. Native `<details>` open/close, zero JS required.
  - **Panel** — `role="menu"`, positioned under the trigger; holds the
    items.
    - **Item** — `role="menuitem"`; an `<a>` when `item.href` is set,
      otherwise a `<button data-id>` that dispatches `apogee:menu` on
      click.
    - **Separator** — an `<hr>`, rendered when `item.separator` is `true`
      (other fields on that item are ignored).

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute
passes through to the root (`role="menubar"`) div.

| Prop | Type | Default | Description |
|---|---|---|---|
| `menus` | `{ label: string; items: MenuItem[] }[]` | — | Top-level menus, in order. |
| `class` | `string` | — | Extra classes on the root, merged last. |

`MenuItem`:

| Field | Type | Description |
|---|---|---|
| `label` | `string` | Item text. |
| `href` | `string` | Renders the item as an `<a>` (navigates). Omit for an action item. |
| `id` | `string` | Passed back in the `apogee:menu` event detail when a `href`-less item is clicked. |
| `separator` | `boolean` | Renders a divider instead of an item. |

- **Closed** (default) — each menu's `<details>` is collapsed.
- **Open** — click, or `Enter` / `Space` on a trigger; siblings auto-close
  (JS); the panel fades and slides in (`--duration-fast`, respects reduced
  motion).
- **Hover / focus** — triggers and items lighten on hover; a visible
  `focus-visible` ring on triggers.
- **No JS** — see the JsNote above: menus still open individually; the
  cross-menu behaviour is JS-only.

## Accessibility

- `role="menubar"` root; each trigger `role="menuitem"` with
  `aria-haspopup="true"`; panel `role="menu"`; items `role="menuitem"`.
- **Keyboard** — native `<details>` gives `Enter` / `Space` to toggle a
  menu; JS adds `←` / `→` to move focus between top-level triggers, and
  `Escape` or an outside click closes any open menu.
- Focus-visible ring on triggers and items.
- **No JS** — every menu still opens and closes on its own (native
  disclosure); auto-closing siblings, arrow-key navigation, and
  outside-click close are JS-only enhancements — nothing is hidden.

## Do / Don't

- **Do** keep top-level labels to one word ("File", "Edit", "View") — this
  is a menubar, not primary navigation.
- **Do** group related actions with a separator instead of one undivided
  list.
- **Don't** nest a Menubar inside another, or use it for page navigation —
  use `Navbar` / `NavLink`.
- **Don't** reuse an item `id` across menus if you handle `apogee:menu`
  globally — give every action item a distinct `id`.

## Content

- Top-level labels: one word, title case ("File", "Edit", "View").
- Item labels: sentence case, verb-led for actions ("New file").
- Trailing `…` on an item that opens another step before acting
  ("Open…").
