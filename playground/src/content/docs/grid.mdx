## Add

```sh
npx @ava-ui/apogee add grid
```

No Apogee dependencies.

## Usage

```astro
---

---
<Grid>
  <Card />
  <Card />
  <Card />
</Grid>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `minItemWidth` | `string` | `'16rem'` | Autofit mode: the smallest a column may get before the count drops. Ignored when `cols` is set. |
| `cols` | `number` | — | Fixed column count. Overrides autofit. |
| `gap` | `0 \| 2 \| 4 \| 6 \| 8 \| 10` | `6` | Gap size (Tailwind `gap-*` scale). |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

Native semantics, no extra ARIA needed. A `<div class="grid">` carries no
implicit role — if the children form a meaningful list, use a list element
(`ul`/`ol`) inside or around it as appropriate.

## Tokens

No CSS custom properties. Column width comes from an inline `grid-template-columns`
(computed from `minItemWidth` or `cols`); gap comes from Tailwind's built-in
`gap-*` spacing scale, not a bespoke token.
