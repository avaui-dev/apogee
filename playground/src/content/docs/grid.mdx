## Add

```sh
npx @ava-ui/apogee add grid
```

No Apogee dependencies.

## Usage

```astro
---
import Grid from '@/components/apogee/Grid/Grid.astro'
---
<Grid>
  <Card />
  <Card />
  <Card />
</Grid>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `minItemWidth` | `string` | `'16rem'` | Autofit mode: the smallest a column may get before the count drops. Ignored when `cols` is set. |
| `cols` | `1 … 12 \| 'auto'`, responsive | — | Fixed column count (overrides autofit). `{ base: 1, md: 3 }` for breakpoints. |
| `gap` | `0 … 6 \| 8 \| 10 \| 12 \| 16`, responsive | `6` | Gap size (Tailwind `gap-*` scale). |
| `colGap` / `rowGap` | `0 \| 1 \| 2 \| 3 \| 4 \| 6 \| 8 \| 10 \| 12` | — | Gap on one axis. |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | — | Vertical alignment of items in their cells. |
| `justify` | `'start' \| 'center' \| 'end' \| 'stretch'` | — | Horizontal alignment of items in their cells. |
| `as` | `string` | `'div'` | Tag to render. |
| `class` | `string` | — | Extra classes, merged last. |

## GridItem

Spans columns or rows; `colSpan` and `rowSpan` accept per-breakpoint objects.

| Prop | Type | Default | Description |
|---|---|---|---|
| `colSpan` | `1 … 12 \| 'full'`, responsive | — | Columns to span. |
| `rowSpan` | `1 … 6`, responsive | — | Rows to span. |
| `colStart` | `1 … 13` | — | Column line to start at. |
| `rowStart` | `1 … 7` | — | Row line to start at. |
| `as` | `string` | `'div'` | Tag to render. |

## Accessibility

Native semantics, no extra ARIA needed. A `<div class="grid">` carries no
implicit role — if the children form a meaningful list, use a list element
(`ul`/`ol`) inside or around it as appropriate.

## Tokens

No CSS custom properties. Column width comes from an inline `grid-template-columns`
(computed from `minItemWidth` or `cols`); gap comes from Tailwind's built-in
`gap-*` spacing scale, not a bespoke token.
