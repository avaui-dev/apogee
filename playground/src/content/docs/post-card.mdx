## Add

```sh
npx @ava-ui/apogee add post-card
```

Pulls in Image, Avatar, Badge and Heading.

## Usage

```astro
---
import PostCard, { type Post } from '@/components/apogee/PostCard/PostCard.astro'
const post: Post = { title: '…', href: '/blog/review-sessions', summary: '…', date: '2026-01-20', category: { name: 'Design' }, author: { name: 'Ada Lovelace' } }
---
<PostCard post={post} />
```

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `post` | `{ title, href, summary?, date, image?, readingTime?, category?, author?, tags? }` | — | Required. `date` is an ISO date; `image` is `{ src, alt, width?, height? }`; `category` and `author` are `{ name, href? }` (the author adds `avatar?`); `tags` are `{ name, href?, color? }[]`. |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | `horizontal` puts the image beside the text once the card is 36rem wide (a container query). |
| `frame` | `'plain' \| 'card' \| 'overlay'` | `'plain'` | No box; a bordered card with the image flush to its top; or author, date and category on a frosted strip over the image. |
| `meta` | `'category' \| 'badge' \| 'byline' \| 'none'` | `'category'` | The line above the title: the category, a badge with the category and reading time, "author • date", or nothing. |
| `footer` | `'author' \| 'tags' \| 'link' \| 'none'` | `'author'` | The author with the date, the tags, a "Read post" line, or nothing. |
| `rounded` | `boolean` | `true` | Rounded image corners (`plain` and `overlay`). |
| `size` | `'medium' \| 'large'` | `'medium'` | `large` for a featured post: a bigger title and a three-line summary. |
| `headingLevel` | `2 \| 3 \| 4 \| 5` | `3` | The title's heading level; one below the list's heading. |
| `linkLabel` | `string` | `'Read post'` | Text of the `link` footer. |
| `locale` | `string` | `'en'` | Date locale. |
| `class` | `string` | — | Extra classes on the `<article>`, merged last. |

## States

- **Hover** — the image zooms a little and the arrow darkens (no zoom under reduced motion).
- **Focus** — the title link shows the focus ring; author, category and tag links have their own.

## Examples

Whole blog layouts built on it: [Blog sections](/docs/blog-sections).

## Accessibility

- The card is an `<article>`. The title is a heading (`headingLevel`) holding the link; the link stretches over the whole card, so a click anywhere opens the post.
- Author, category and tag links sit above the stretched link and stay reachable by keyboard and pointer.
- The arrow is `aria-hidden`; give the image an empty `alt` when it only illustrates the title.
- The tags are a list named "Tags".

## Tokens

| Token | Used for |
|---|---|
| `--foreground-primary` | Category and byline line |
| `--foreground-neutral` / `--foreground-neutral-faded` | Title / summary and date |
| `--border-neutral` / `--background-elevation-raised` | `card` frame |
| `--background-inverted` / `--on-inverted` | `overlay` strip |

## Do / Don't

- **Do** keep summaries to two lines; the card clamps longer ones.
- **Don't** put a second link on the summary; the whole card already opens the post.

## Content

- Titles say what the reader learns, not just the topic.
