## Add

```sh
npx @ava-ui/apogee add heading
```

No Apogee dependencies.

## Usage

```astro
---
import Heading from '@/components/apogee/Heading/Heading.astro'
---
<Heading as="h1">Page title</Heading>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native heading/text
attribute (e.g. `id`, `aria-level`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6' \| 'p' \| 'div'` | `'h2'` | Semantic tag rendered. |
| `size` | `'display' \| 'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6'` | mirrors `as` (falls back to `h2` when `as` is `p`/`div`) | Visual size, independent of the semantic tag. |
| `weight` | `'regular' \| 'medium' \| 'semibold' \| 'bold'` | `'semibold'` | Font weight. |
| `color` | `'neutral' \| 'neutral-faded' \| 'primary' \| 'critical' \| 'positive' \| 'warning'` | — | Text hue. Unset inherits the surrounding colour, so a heading inside a solid fill keeps the on-colour. |
| `maxLines` | `1 \| 2 \| 3` | — | Clamp with an ellipsis. |
| `align` | `'start' \| 'center' \| 'end'` | — | Text alignment. |
| `class` | `string` | — | Extra classes, merged last. |

## Examples

Decouple visual weight from document order — a card title that's semantically
an `h3` but should look smaller than the page's other `h3`s:

```astro
<Heading as="h3" size="h5">Card title</Heading>
```

## Accessibility

- Renders the real tag passed to `as` — screen readers get an accurate heading
  outline.
- Keep heading order sequential (h1 → h2 → h3, no skipping) even when `size`
  makes the visual weight diverge from `as`.
- `as="p"` / `as="div"` removes the element from the heading outline entirely —
  use it when text should merely *look* like a heading without appearing in
  the page's structure.
- Native semantics, no extra ARIA needed.

## Tokens

| Token | Used for |
|---|---|
| `--text-display` / `--text-h1` … `--text-h6` (each paired with its own line-height) | Fluid font size + line height per `size` |
| `--foreground-neutral` | Text colour |

## Do / Don't

- **Do** choose `as` for correct document outline first, then adjust `size`
  for visual weight.
- **Do** keep exactly one `h1` per page.
- **Don't** skip heading levels for visual reasons — use `size` instead of
  jumping from `h2` to `h5`.
- **Don't** use `Heading` to style body copy — reach for `as="p"`/`as="div"`
  only when the text is heading-like but shouldn't join the outline.

## Content

- Short, front-loaded phrases — lead with the key word, sentence case, no
  ending period.
- Avoid vague headings ("More information") — name the actual content.
