## Add

```sh
npx @ava-ui/apogee add choice-card
```

Depends on `utils` (`uid`). Zero JS.

## Usage

```astro
---
import ChoiceCard from '@/components/apogee/ChoiceCard/ChoiceCard.astro'
---
<form>
  <ChoiceCard name="plan" value="free" title="Free" description="One project." />
  <ChoiceCard name="plan" value="pro" title="Pro" description="Unlimited projects." checked />
</form>
```

## Anatomy

A `<label>` is the card. Inside, in order: the hidden native input (`sr-only`),
the optional `start` slot, the title and description column, the optional
`end` slot, and the selection mark (a radio dot or a check) at `indicatorPosition`.
Because the control is native, arrows move between radios that share a `name`,
Space toggles a checkbox, and the form posts `name=value`.

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<label>`
attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `type` | `'radio' \| 'checkbox'` | `'radio'` | The native control. Radios that share `name` are one group. |
| `name` | `string` | — | Required. Form field name. |
| `value` | `string` | — | Required. Posted when selected. |
| `checked` | `boolean` | `false` | Initial state. |
| `disabled` | `boolean` | `false` | Disables the control and dims the card. |
| `required` | `boolean` | `false` | Native `required` on the input. |
| `title` | `string` | — | Title text; the default slot replaces it. |
| `description` | `string` | — | Supporting text under the title, read as the control's description. The `description` slot replaces it. |
| `indicator` | `'radio' \| 'check' \| 'none'` | matches `type` | The selection mark. |
| `indicatorPosition` | `'start' \| 'end'` | `'end'` | Which side the mark sits on. |
| `size` | `'small' \| 'medium'` | `'medium'` | Padding and gap. |
| `id` | `string` | generated | Id of the input. |
| `class` | `string` | — | Extra classes on the card, appended last. |

Slots: `start` (icon, avatar, logo), default (title), `description`, `end` (price, badge).

- **Hover** — the neutral faded fill.
- **Selected** — primary border plus a 1px inset ring; the mark fills.
- **Focus** — the shared focus outline on the card when the hidden input has keyboard focus.
- **Disabled** — disabled tokens, `cursor-not-allowed`, the mark dims.

## Accessibility

- The card is a `<label>` for a real `<input>`; the name is the title text, and `description` is wired through `aria-describedby`.
- Keyboard: Tab reaches the group (the checked radio, or the first), arrows move and select between radios with the same `name`, Space toggles a checkbox.
- The focus ring draws on the card (`:has(:focus-visible)`), so it is visible although the input is visually hidden.
- Group radios in a `<fieldset>` with a `<legend>` when the set needs a name of its own.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` / `--border-primary` | Card border, selected border and inset ring |
| `--background-page` / `--background-neutral-faded-highlighted` | Card fill, hover |
| `--background-primary` / `--on-primary` | The filled mark and its dot or check |
| `--background-disabled` / `--foreground-disabled` / `--border-disabled` | Disabled |
| `--outline-color-focus` | Focus ring |

## Do / Don't

- **Do** use it when each option needs more than a label: a description, a price, an icon.
- **Do** keep every card in a group the same height; put them in a grid.
- **Don't** mix radio and checkbox cards in one group.
- **Don't** put links or buttons inside; a click anywhere selects the card.

## Content

- Title: two or three words, a noun ("Pro", "Daily backups").
- Description: one short sentence or a fragment; no trailing period on fragments.
