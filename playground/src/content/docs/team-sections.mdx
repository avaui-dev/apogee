Each example is a block: a [Section](/docs/section) with a
[SectionHeader](/docs/section-header) and a list of people. Each person has
a photo, a name (a heading), a role, and in most layouts a short bio and
three links. The scrolling rows use [Carousel](/docs/carousel); the glass
panels sit on the photo with a frosted surface that keeps the text readable.

```sh
npx @ava-ui/apogee add team/simple-01
```

## Copy is props

Every block in this family takes the same content props (`TeamContent` in
`sections/_shared/team.ts`), with its sample copy as the defaults. A block
ignores the props it has no place for, so you can swap one block for another and
keep the copy. The [Team](/docs/sections/team) section takes the same names for the props they share.

- `eyebrow`: The small label above the heading.
- `heading`: The heading.
- `description`: The line under the heading.
- `label`: Accessible name for the landmark or the people carousel.
- `items`: People.
- `primaryAction`: The solid button by the heading.
- `secondaryAction`: The outline button by the heading.

- Pass `null` to hide an optional part, such as `description={null}`.
- Some blocks add props of their own; the top of each block's file lists them.
