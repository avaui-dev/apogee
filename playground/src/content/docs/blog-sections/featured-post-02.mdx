## Add

```sh
npx @ava-ui/apogee add blog/featured-post-02
```

Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/blog-sections#copy-is-props).

This copies the block to `src/components/apogee/blocks/blog/` with everything it uses: Grid, Input, Pagination, PostCard, Section, SectionHeader, Tabs. It opens a blog index page (its heading is the page's `h1`). Swap the `posts` array for your content collection. Use **Copy code** above to paste it instead.

## Accessibility

- Each post is one link: the title stretches over the card, and the author, category and tag links sit above it and stay clickable.
- The decorative arrow and the images are hidden from screen readers (their alt is empty because the title already names the post).
- The category row is a `<nav>` named "Categories"; the current category carries `aria-current="page"`.
- The search field is named "Search posts".
- Pagination is a `<nav>` of links; the current page carries `aria-current="page"`.
