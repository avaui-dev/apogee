## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root element.

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | `horizontal` renders an `<hr>` (a `<div role="separator">` when labelled); `vertical` renders a `<div>` sized to stretch its flex/grid container. |
| `color` | `'neutral' \| 'neutral-faded'` | `'neutral'` | Line colour. |
| `contentPosition` | `'start' \| 'center' \| 'end'` | `'center'` | Where a label sits on a horizontal `line` divider. |
| `variant` | `'line' \| 'dual' \| 'fill'` | `'line'` | How labelled content is framed: between the halves of one rule, centred between two rules, or on a filled band. |
| `interactive` | `boolean` | `false` | The slot holds a button or group: drops the separator role and the faded text colour. |
| `inset` | `0 \| 2 \| 4 \| 6 \| 8` | — | Margin along the main axis. |
| `class` | `string` | — | Extra classes, merged last. |

No interactive states — a static separator.

Between toolbar items:


## Accessibility

- `horizontal` is a real `<hr>` — implicit `separator` role, no extra ARIA
  needed.
- `vertical` is a `<div role="separator" aria-orientation="vertical">`, since
  `<hr>` only carries horizontal semantics.
- A labelled divider is a `<div role="separator">` around the text. With
  `interactive` the role is dropped: a separator must not contain a control,
  and the button keeps its own name and colour.
