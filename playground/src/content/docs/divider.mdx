## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root element.

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | `horizontal` renders an `<hr>`; `vertical` renders a `<div>` sized to stretch its flex/grid container. |
| `color` | `'neutral' \| 'neutral-faded'` | `'neutral'` | Line colour. |
| `contentPosition` | `'start' \| 'center' \| 'end'` | `'center'` | Where a label sits on a horizontal divider. |
| `inset` | `0 \| 2 \| 4 \| 6 \| 8` | — | Margin along the main axis. |
| `class` | `string` | — | Extra classes, merged last. |

### Labelled

Text in the default slot renders between the lines; `contentPosition` moves it. The line follows the text direction in RTL.

## States

No interactive states — a static separator.

## Examples

Between toolbar items:

```astro
<div class="flex h-10 items-center gap-3">
  <Button variant="ghost" color="neutral" iconOnly aria-label="Bold">B</Button>
  <Divider orientation="vertical" />
  <Button variant="ghost" color="neutral" iconOnly aria-label="Italic">I</Button>
</div>
```

## Accessibility

- `horizontal` is a real `<hr>` — implicit `separator` role, no extra ARIA
  needed.
- `vertical` is a `<div role="separator" aria-orientation="vertical">`, since
  `<hr>` only carries horizontal semantics.
