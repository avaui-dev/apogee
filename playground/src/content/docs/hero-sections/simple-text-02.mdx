## Add

```sh
npx @ava-ui/apogee add hero/simple-text-02
```

This copies the block to `src/components/apogee/blocks/hero/` with everything it uses: Button, Heading, Image, Section. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/hero-sections#copy-is-props).

## Accessibility

- The heading is the page's `h1`; the items below are one level down.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
