## Add

```sh
npx @ava-ui/apogee add hero/framed-split-01
```

This copies the block to `src/components/apogee/blocks/hero/` with everything it uses: Badge, Button, Heading, Image, Section, Select. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/hero-sections#copy-is-props).

## Theming

- The tint mixes the primary hue into the page colour, so it follows light and dark mode and your brand colour.
- The status card is always dark (`data-theme="dark"`), with the same hue mixed in.

## Accessibility

- The heading is the page's `h1`; the faded first half is part of the same heading.
- The industry picker is a native select with a visible "Industry" label; it works without JS.
- The readout is a description list, so each value is read with its name.
- The ruler and corner brackets are hidden from assistive tech.
