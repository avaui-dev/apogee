## Add

```sh
npx @ava-ui/apogee add forgot-password/set-new-password
```

This copies the page to `src/components/apogee/pages/forgot-password/` with everything it uses: AuthShell, Button, FeaturedIcon, Input, PasswordChecklist. Render it from one of your routes, or use **Copy code** above.

## Accessibility

- The page heading is the `h1`; the "Back to log in" arrow flips under right-to-left text.
- The rules are part of the password field's description, and the field stays invalid until they hold. The confirm field stays invalid until it matches. See [PasswordChecklist](/docs/password-checklist).
