## Add

```sh
npx @ava-ui/apogee add forgot-password/forgot-password
```

This copies the page to `src/components/apogee/pages/forgot-password/` with everything it uses: AuthShell, Button, FeaturedIcon, Input. Render it from one of your routes, or use **Copy code** above.

## Accessibility

- The page heading is the `h1`; the "Back to log in" arrow flips under right-to-left text.
- The email field has `autocomplete="email"`, so the browser fills it.
- Say the same thing whether or not the address has an account, so the page does not reveal who is signed up.
