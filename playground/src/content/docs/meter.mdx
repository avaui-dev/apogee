## Add

```sh
npx @ava-ui/apogee add meter
```

No Apogee dependencies.

## Usage

```astro
---
import Meter from '@/components/apogee/Meter/Meter.astro'
---
<Meter value={72} label="Disk usage" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native
`<meter>` attribute passes through (`...rest`).

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | — | The current measurement. |
| `min` | `number` | `0` | Range floor. |
| `max` | `number` | `100` | Range ceiling. |
| `low` | `number` | — | Below this counts as sub-optimal (warning colour). |
| `high` | `number` | — | Above this counts as sub-optimal (warning colour). |
| `optimum` | `number` | — | The ideal point — the browser derives the good / warning / danger zones from it. |
| `label` | `string` | — | Visible label, shown with a `value/max` readout. Omit for an unlabelled bar. |
| `class` | `string` | — | Extra classes on the wrapper, merged last. |

## States

No interactive states — Meter is a static, read-only gauge (not focusable).

## Examples

A "bigger is better" gauge — `optimum` at the top of the range:

```astro
<Meter value={82} low={40} high={70} optimum={100} label="Score" />
```

## Accessibility

Native semantics, no extra ARIA needed — `<meter>` exposes its value, range,
and zone to assistive tech on its own. Pair it with a visible `label` when the
measurement's meaning isn't obvious from context.

## Tokens

| Token | Used for |
|---|---|
| `--background-neutral-faded` | Track background |
| `--background-primary` | Optimum-zone fill |
| `--background-warning` | Sub-optimal zone fill |
| `--background-critical` | Even-less-good zone fill |

## Do / Don't

- **Do** use Meter for a static measurement against a known range (disk
  usage, a score, capacity).
- **Do** set `low` / `high` / `optimum` whenever "good" and "bad" have a
  real meaning — the colour zones are meaningless without them.
- **Don't** use Meter for task completion — use `Progress` instead.
- **Don't** omit `label` when the number alone is ambiguous (what's being
  measured, and its unit).

## Content

- Label names the thing being measured, not the number ("Disk usage", not
  "72%").
- Keep the label to a few words — the value/max readout sits next to it.
