## Add

```sh
npx @ava-ui/apogee add metrics/minimal-centered-text
```

This copies the block to `src/components/apogee/blocks/metrics/` with everything it uses: Section. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/metrics-sections#copy-is-props).
