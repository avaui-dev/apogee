## Add

```sh
npx @ava-ui/apogee add metrics/split-image-02-brand
```

This copies the block to `src/components/apogee/blocks/metrics/` with everything it uses: Image, Section, SectionHeader. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
