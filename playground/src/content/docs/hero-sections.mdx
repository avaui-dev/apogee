Each example is a block: a [Section](/docs/section) with the page's `h1`,
supporting text and actions, next to an image, a sign-up form, a
[DeviceFrame](/docs/device-frame) mockup, a card or a background pattern.

```sh
npx @ava-ui/apogee add hero/split-image-01
```

## Copy is props

Every hero block takes the same content props, with its sample copy as the
defaults: `announcement` (`{ badge?, label, href }`), `eyebrow`, `heading`,
`description`, `primaryAction` and `secondaryAction` (`{ label, href }`) and
`media` (`{ src, srcDark?, alt, width?, height? }`). A block ignores the ones it
has no place for, so you can swap one hero block for another and keep the copy.
Some blocks add their own, such as `submitLabel` or `images`.

- Wrap words of the heading in `*asterisks*` to accent them. Each block styles
  the accent its own way (underlined, faded, italic); a block without an accent
  style drops the asterisks.
- Pass `null` to hide a part: `announcement={null}`, `secondaryAction={null}`.
