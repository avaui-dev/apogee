## Add

```sh
npx @ava-ui/apogee add radio
```

No Apogee component dependencies.

## Usage

```astro
---
import Radio from '@/components/apogee/Radio/Radio.astro'
---
<Radio name="plan" value="free" label="Free" checked />
<Radio name="plan" value="pro" label="Pro" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<input>`
attribute (e.g. `checked`, `disabled`, `required`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` | `string` | — | Group name — give every radio in the set the same value. |
| `value` | `string` | — | This radio's value, submitted when checked. |
| `label` | `string` | — | Visible label, rendered in a `<label>` next to the input. Rich labels go in the default slot instead. |
| `id` | `string` | auto-generated | Ties the label to the input; set your own to target it elsewhere. |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Control and label size. |
| `hasError` | `boolean` | `false` | Marks the control invalid (`aria-invalid`, critical border). |
| `hint` | `string` | — | Supporting text under the label; the input lists it in `aria-describedby`. The label turns medium weight to read as a heading. |
| `class` | `string` | — | Extra classes on the wrapping `<div>`. |

## States

- **Unchecked / Checked** — native `:checked`; a filled accent dot fades in.
- **Hover** — border darkens on an unchecked, enabled radio.
- **Focus** — a visible `focus-visible` ring (`--border-primary`).
- **Disabled** — dimmed, pointer becomes `not-allowed`. Pass the native
  `disabled` attribute.

## Accessibility

- Real `<input type="radio">` — keyboard and AT support for free: `Tab` moves
  into the group, arrow keys move and select between radios that share a
  `name`.
- Focus ring is always visible on keyboard focus.
- Every radio needs a label — pass `label`, or an `aria-label` if you supply
  your own markup instead.
- Give every radio in a group the exact same `name` so the browser treats
  them as one set.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Unchecked border |
| `--foreground-neutral-faded` | Hover border (unchecked, enabled) |
| `--background-primary` | Checked border + fill |
| `--background-page` | Unchecked fill |
| `--outline-color-focus` | Focus ring |

## Do / Don't

- **Do** use Radio for a single choice from 2–5 mutually exclusive,
  always-visible options.
- **Do** give every radio in a group the same `name`.
- **Don't** use a lone Radio outside a group — a single yes/no choice is a
  `Checkbox` or `Switch`.
- **Don't** let the option list grow past ~6 — switch to `Select`.

## Content

- Label is a short noun phrase naming the option (not a question), sentence
  case, no ending punctuation.
