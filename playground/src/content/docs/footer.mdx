## Add

```sh
npx @ava-ui/apogee add footer
```

No Apogee dependencies. Pairs well with `Grid` for the column layout.

## Usage

```astro
---
import Footer from '@/components/apogee/Footer/Footer.astro'
---
<Footer>
  <nav>…link columns…</nav>
  <p slot="bottom">© 2026 Larkspur, Inc.</p>
</Footer>
```

## Anatomy

- **Default slot** — the main content, typically a `Grid` of link-list columns.
- **`bottom`** slot (optional) — a row below a top divider, laid out as a
  column on mobile and a row (space-between) from `sm:` up. Renders only when passed.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<footer>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `class` | `string` | — | Extra classes on the root, merged last. |

## States

Static: no interactive states. Links inside keep their own hover and focus states.

## Accessibility

Native semantics — renders a real `<footer>` landmark, no extra ARIA needed.
Links inside it keep their own keyboard behaviour.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Top border of the footer and of the `bottom` row |
| `--foreground-neutral-faded` | `bottom` row text colour |

## Do / Don't

- **Do** use `Grid` (or another layout primitive) inside the default slot for multi-column links.
- **Do** keep the `bottom` row to copyright + a short legal link list.
- **Don't** put primary navigation or a CTA that belongs in the header here.
- **Don't** nest another `Footer` inside it.

## Content

- Column headings are short nouns ("Product", "Company"), sentence case, no ending punctuation.
- Bottom copyright line: `© {year} {name}`, no trailing period.
