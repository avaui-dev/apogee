## Add

```sh
npx @ava-ui/apogee add banner/countdown-brand
```

Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/banner-sections#copy-is-props).

This copies the block to `src/components/apogee/blocks/banner/` with everything it uses: Banner, Countdown. Place it at the top of a page, or pass `fixed` to a floating banner to pin it to the bottom of the viewport. Use **Copy code** above to paste it instead.

## Accessibility

- The banner is a region named by its message, so it shows up in a screen reader's landmark list.
- The close button removes the banner; it needs JS, so it hides without it and the banner stays.
- Screen readers and no-JS visitors read the end date ("Ends Dec 31, 2026, 11:59 PM UTC"); the ticking numbers are hidden from them, so nothing is announced every second.
