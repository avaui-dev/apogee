## Add

```sh
npx @ava-ui/apogee add banner/single-action-brand-full-width
```

This copies the block to `src/components/apogee/blocks/banner/` with everything it uses: Banner, Button, FeaturedIcon. Place it at the top of a page, or pass `fixed` to a floating banner to pin it to the bottom of the viewport. Use **Copy code** above to paste it instead.

## Accessibility

- The banner is a region named by its message, so it shows up in a screen reader's landmark list.
- The close button removes the banner; it needs JS, so it hides without it and the banner stays.
