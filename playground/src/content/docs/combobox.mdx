## Add

```sh
npx @ava-ui/apogee add combobox
```

Pulls in `Field` (label, hint, error scaffold) and `utils`. Uses
`@lucide/astro` internally (`ChevronDown`) for the caret — no icon import
needed in your usage.

## Usage

```astro
---
import Combobox from '@/components/apogee/Combobox/Combobox.astro'
---
<Combobox label="Country" options={['Canada', 'France', 'Germany', 'Japan']} />
<Combobox label="Assignee" name="assignee" options={[
  { value: 'u1', label: 'Ada Lovelace', description: 'Engineering' },
  { value: 'u2', label: 'Grace Hopper', description: 'Research', disabled: true },
]} />
```

## Anatomy

- **Label / hint / error** — from `Field`.
- **Input** — the visible text field, `role="combobox"`.
- **Caret** — optional chevron icon (toggle with `caret`).
- **Listbox** — a `role="listbox"` popover of `role="option"` suggestions,
  anchored under the input and as wide as it, filtered as you type; scrolls
  past 15rem.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the input (e.g. `placeholder`, `disabled`, `name`).

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated | Input id; drives the listbox id (`${id}-list`) and `Field` wiring. |
| `label` | `string` | — | Field label. |
| `hint` | `string` | — | Helper text (hidden when `error` is set). |
| `error` | `string` | — | Error text; sets `aria-invalid` and renders via `role="alert"`. |
| `options` | `(string \| { value, label?, description?, disabled?, icon?, avatar?, avatarName? })[]` | — | Suggestions. A string is both value and label; an object can carry a different `value`, a `description` line, `disabled`, and media before the label (a Lucide component, or an image URL with `avatarName` for the fallback). Required. |
| `size` | `'small' \| 'medium' \| 'large' \| 'xlarge'` | `'medium'` | Height: 28 / 36 / 48 / 56px. |
| `variant` | `'outline' \| 'faded' \| 'ghost' \| 'headless'` | `'outline'` | The box style: bordered, tinted, bare, or no box at all. |
| `hasError` | `boolean` | `false` | Marks the field invalid (`aria-invalid`, critical border) without an `error` message. |
| `required` | `boolean` | `false` | Marks the input required (native + `Field`'s `*` indicator). |
| `caret` | `boolean` | `true` | Shows the chevron caret. Set `false` to hide it. |
| `multiple` | `boolean` | `false` | Picks become removable chips inside the field; each posts `name=value` through a hidden input, chosen options leave the list, Backspace on an empty input removes the last chip. |
| `name` | `string` | — | Form field name (required with `multiple`). |
| `value` | `string \| string[]` | — | Initial text (single), or initial chips as option values (`multiple`). |
| `maxItems` | `number` | — | Stops accepting picks at this count. |
| `class` | `string` | — | Extra classes, passed to the `Field` wrapper. |

## States

- **Default** — closed, empty or pre-filled input.
- **Open** — focusing or typing in the input opens the listbox; the closest
  match is highlighted (`aria-selected` + `aria-activedescendant`).
- **Error** — critical border, `aria-invalid="true"`, error text replaces
  the hint.
- **Disabled** — via passthrough `disabled`; dimmed, not interactive.
- **No JS** — the listbox never opens; the input is a plain text field.

## Events

Committing an option (Enter or click) writes its label into the input and
dispatches native `input` and `change` events plus `apogee:combobox-select`
(`detail: { value, label }`, bubbles) on the root, so forms and listeners see
the selection. The input submits the label; read `value` from the event when
the two differ.

## Accessibility

- Full ARIA combobox pattern: `role="combobox"` on the input, wired with
  `aria-expanded`, `aria-controls`, `aria-autocomplete="list"`, and
  `aria-activedescendant` on the highlighted option; `role="listbox"` /
  `role="option"` with `aria-selected` on the dropdown; disabled options
  carry `aria-disabled`.
- **Keyboard** — focus opens the list and shows every option; typing filters
  and highlights the closest prefix match; `↓` / `↑` move the highlight and
  wrap (opening the list first if closed); `Enter` commits the highlighted
  option; `Escape` closes the list.
- Clicking an option commits it without losing input focus.
- Focus leaving the whole widget (tab away, click elsewhere) closes the list.
- **No JS:** the listbox is a closed popover and never opens — the input
  still works as a plain, free-typed text field that submits under its
  `name`.

## Do / Don't

- **Do** keep `options` short and relevant — it's a suggestion list, not a
  full dataset; filter server-side before passing in a large set.
- **Do** allow free text — Combobox never forces a value from `options`.
- **Don't** use Combobox when the value must be constrained to the list — use
  `Select` instead.
- **Don't** rely on `disabled` to lock in a submitted value — a disabled
  input doesn't submit at all.

## Content

- Label names the field ("Country"), not the widget ("Combobox").
- Error copy states what's wrong or what format is expected.
