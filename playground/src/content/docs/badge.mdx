## Add

```sh
npx @ava-ui/apogee add badge
```

No component dependencies.

## Usage

```astro
---
import Badge from '@/components/apogee/Badge/Badge.astro'
---
<Badge color="primary" variant="solid">New</Badge>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<span>`
attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning'` | `'neutral'` | The hue. |
| `variant` | `'solid' \| 'faded' \| 'outline'` | `'faded'` | The fill style. |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Height: 20 / 24 / 28px. |
| `rounded` | `boolean` | `false` | Fully round ends. |
| `highlighted` | `boolean` | `false` | Stronger fill for an active filter or selected state. |
| `truncate` | `boolean` | `false` | Clamps long labels (max 10rem) with an ellipsis. |
| `class` | `string` | — | Extra classes, appended last. |

Slots: `start` and `end` for a small icon.

  </BadgeContainer>
  <BadgeContainer position="bottom-end" overlap>
    <Avatar name="Alan Turing" />
    <Badge slot="badge" variant="solid" color="positive" rounded size="small">3</Badge>
  </BadgeContainer>
</Preview>

| Prop | Type | Default | Description |
|---|---|---|---|
| `position` | `'top-end' \| 'bottom-end'` | `'top-end'` | Corner the badge sits on. |
| `overlap` | `boolean` | `false` | Pushes the badge outward for round elements. |
| `class` | `string` | — | Extra classes on the wrapper. |

Static — a `<span>`, not a control. No hover/focus/disabled states. If a badge
needs to be clickable (a removable filter chip), wrap it in a `<button>`
yourself; Badge doesn't provide one.

## Accessibility

Native semantics, no extra ARIA needed for a static label. If a badge's count
updates live (e.g. an unread counter), pass `aria-live="polite"` via passthrough
so assistive tech picks up the change.

## Tokens

| Token | Used for |
|---|---|
| `--background-{hue}-faded` / `--foreground-{hue}` | `faded` variant, per `color` |
| `--background-{hue}` / `--on-{hue}` | `solid` variant |
| `--border-{hue}` / `--foreground-{hue}` | `outline` variant |

## Do / Don't

- **Do** keep badge text to one or two words, or a short number.
- **Do** reserve `danger` for genuinely negative states (errors, overdue) — not just to draw attention.
- **Don't** use Badge as a button — it has no focus or press states.
- **Don't** wrap long sentences in a Badge; it doesn't wrap gracefully and isn't meant to hold prose.

## Content

- Sentence case or a single number, no ending period. Prefer a status word ("Active", "Beta", "12") over a phrase.
