## API

`@composable` — exposed to Content Editors in AVA. Any other native attribute
for the rendered tag (e.g. `id`, `aria-label`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `'p' \| 'span' \| 'div' \| 'label' \| 'li' \| 'strong' \| 'em' \| 'small'` | `'p'` | Element rendered. |
| `size` | `'small' \| 'medium' \| 'large'`, responsive | `'medium'` | Font size: 14 / 16 / 18px; `{ base: 'small', md: 'medium' }` per breakpoint. |
| `weight` | `'regular' \| 'medium' \| 'semibold' \| 'bold'` | `'regular'` | Font weight. |
| `maxLines` | `1 … 6` | — | Clamp with an ellipsis (`1` also breaks long words). |
| `numeric` | `boolean` | `false` | Tabular figures for aligned digits. |
| `align` | `'start' \| 'center' \| 'end'` | — | Text alignment. |
| `color` | `'neutral' \| 'neutral-faded' \| 'primary' \| 'critical' \| 'positive' \| 'warning'` | — | Body text, secondary text, or a hue. Unset inherits, so text on a solid fill keeps the on-colour. |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

Native semantics, no extra ARIA needed. `as` picks a plain, non-semantic tag
(`p` / `span` / `div`) — for headings, lists, or other meaningful structure, use
the tag or component that carries that meaning instead of `Text`.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-neutral` | Default text color |
| `--foreground-neutral-faded` | `color="neutral-faded"` text |

## Do / Don't

- **Do** use `color="neutral-faded"` for secondary/supporting copy (timestamps, helper text).
- **Do** pick `as` to match the surrounding flow (`span` inside a line, `div` /
  `p` as a block).
- **Don't** use `Text` for headings — it has no heading semantics or size scale
  for that.
- **Don't** hard-code font size or colour classes; use `size` and `color`.

## Content

- Sentence case. No filler ("please note", "simply") — say the thing.
- Keep line length readable; let `leading-relaxed` do the work rather than
  forcing breaks.
