Each example is a block built on [JobCard](/docs/job-card) and the layout
primitives: a heading, then the open positions as rows under a rule or as
cards, sometimes grouped by department or filtered with tabs.

```sh
npx @ava-ui/apogee add careers/simple-01
```

Each block holds a sample `jobs` array at the top; replace it with yours (a
content collection, or your applicant tracking system's feed).
