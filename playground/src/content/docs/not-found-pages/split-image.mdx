## Add

```sh
npx @ava-ui/apogee add not-found/split-image
```

This copies the page to `src/components/apogee/pages/not-found/` with everything it uses: Image, NotFound. Render it from `src/pages/404.astro`, or use **Copy code** above.

## Accessibility

- The page heading is the `h1`.
- "Go back" returns to the previous page (or home when the page was opened directly). It needs JS, so it hides without it; "Take me home" always works.
- The photo has empty alt text: it is decoration.
