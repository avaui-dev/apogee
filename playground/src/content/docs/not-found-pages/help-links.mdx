## Add

```sh
npx @ava-ui/apogee add not-found/help-links
```

This copies the page to `src/components/apogee/pages/not-found/` with everything it uses: Link, NotFound. Render it from `src/pages/404.astro`, or use **Copy code** above.

## Accessibility

- The page heading is the `h1`.
- "Go back" returns to the previous page (or home when the page was opened directly). It needs JS, so it hides without it; "Take me home" always works.
- The help links are a plain list of links, each with a line of context.
