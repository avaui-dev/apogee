## Add

```sh
npx @ava-ui/apogee add icon-toggle
```

No dependencies; pair it with `toggle-button`.

## Usage

```astro
---
import IconToggle from '@/components/apogee/IconToggle/IconToggle.astro'
import ToggleButton from '@/components/apogee/ToggleButton/ToggleButton.astro'
import { Star } from '@lucide/astro'
---
<ToggleButton iconOnly aria-label="Star">
  <IconToggle><Star slot="off" /><Star slot="on" class="fill-current" /></IconToggle>
</ToggleButton>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<span>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `on` | `boolean` | `false` | Which icon shows. Rendered as `data-on`; flip that attribute to swap. |
| `label` | `string` | — | Accessible name (`role="img"`). Omit inside a labelled control, where the toggle is decorative. |
| `class` | `string` | — | Extra classes; set the size here (`size-5`). |

Slots: `off` and `on`, one icon each.

## States

- **Off / on** — the hidden icon is scaled to 60% and transparent; the swap
  takes `--duration-fast`.
- **Reduced motion** — the swap is instant.

## Accessibility

- Inside a ToggleButton the state is the button's `aria-pressed`; the toggle
  is `aria-hidden`.
- Standalone, give it a `label` that names the current state, and update it
  when you flip `data-on`.

## Tokens

| Token | Used for |
|---|---|
| `--duration-fast` / `--ease-standard` | Swap transition |

## Do / Don't

- **Do** pair outline and filled versions of the same glyph (heart, star,
  bookmark) so the swap reads as one control changing state.
- **Don't** use two unrelated icons for an on/off pair; use two buttons.

## Content

- The button's `aria-label` names the action, and stays the same in both states ("Bookmark"); `aria-pressed` carries the on/off state.
