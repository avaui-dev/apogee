## Add

```sh
npx @ava-ui/apogee add popover
```

Depends on `utils` (the anchored-panel helper). No icons. Zero JS — the
native Popover API (`popover`, `popovertarget`) plus CSS anchor positioning
do the work.

## Usage

```astro
---
import Popover from '@/components/apogee/Popover/Popover.astro'
---
<Popover placement="bottom-start" width="trigger">
  <span slot="trigger">Filters</span>
  <p>Panel content goes here.</p>
</Popover>
```

## Anatomy

- **Trigger** — the built-in `<button popovertarget>`; its label is the
  `trigger` slot (defaults to "Open").
- **Anchor** — alternatively, your own element in the `anchor` slot. Give
  it `popovertarget={id}` and pass the same `id` to the Popover.
- **Panel** — the `<div popover>` anchored to the trigger; its content is
  the default slot. It paints in the top layer, so no ancestor can clip it.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the trigger (the built-in button, or the wrapper around your
`anchor` element).

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated | Panel id. Set it when an `anchor` element needs `popovertarget`. |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'start' \| 'start-top' \| 'start-bottom' \| 'end' \| 'end-top' \| 'end-bottom'` | `'bottom'` | Side and alignment. `start`/`end` are logical and mirror in RTL. The panel flips to the opposite side when there is no room. |
| `gap` | `number` | `2` | Space between trigger and panel, in spacing steps (2 = 0.5rem). |
| `width` | `'trigger' \| string` | — | `'trigger'` matches the trigger's width; otherwise any CSS length. |
| `maxHeight` | `string` | — | Caps the panel height; content scrolls past it. |
| `padding` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | `4` | Panel padding in spacing steps. |
| `elevation` | `'raised' \| 'overlay'` | `'overlay'` | Surface and shadow of the panel. |
| `panelClass` | `string` | — | Extra classes on the panel. |
| `class` | `string` | — | Extra classes on the trigger, merged last. |

panel is in the top layer, so an `overflow: hidden` ancestor cannot clip it.

## Custom trigger

Put your own element in the `anchor` slot with `popovertarget` set to the
Popover's `id`. The element must be a `<button>` (or any element with
invoker support) so it works with zero JS.

## States

- **Closed → open** — a fade + slight scale (`--duration-fast`,
  `--ease-standard`), using `@starting-style` for the entry transition;
  driven entirely by the browser's `:popover-open` pseudo-class.
- **Out of room** — the panel flips to the opposite side, then the opposite
  alignment, with no JS.
- **Unsupported anchor positioning** — the panel falls back to the popover
  API's default centered position, still fully usable. Anchor positioning is
  Baseline since January 2026.

## Accessibility

| Key | Action |
|---|---|
| `Enter` `Space` | On the trigger, toggle the panel. |
| `Esc` | Closes the panel and returns focus to the trigger (native). |

- The trigger is a real `<button popovertarget>`; the browser sets
  `aria-expanded` on it.
- Clicking outside closes the panel — the browser's native light-dismiss
  behaviour (`popover="auto"`, the implicit default), no JS involved.
- The panel paints in the native top layer, above everything else, with no
  `z-index` needed.
- The panel has no implicit ARIA role — if its content behaves like a dialog or
  menu, add `role="dialog"` / `role="menu"` (and a label) yourself.
- Opening doesn't move focus into the panel — there's no `autofocus`. Add one to
  a focusable child if the panel needs immediate keyboard interaction.
- The open/close fade is disabled under `prefers-reduced-motion: reduce`.

| Token | Used for |
|---|---|
| `--border-neutral` | Trigger + panel border |
| `--background-page` | Trigger background |
| `--background-elevation-overlay` / `-raised` | Panel background (`elevation`) |
| `--foreground-neutral` | Trigger + panel text |
| `--background-neutral-faded-highlighted` | Trigger hover background |
| `--outline-color-focus` | Focus ring |
| `--duration-fast` / `--ease-standard` | Open/close transition |
| `--radius-md` | Trigger corner radius |
| `--radius-lg` | Panel corner radius |

## Do / Don't

- **Do** keep the panel's first interactive element reachable by `Tab` — there's
  no focus trap, so keyboard order just follows DOM order.
- **Do** use `width="trigger"` for panels that act like a picker under a field.
- **Don't** put a page's primary content only in a Popover — a stray click or
  `Esc` dismisses it.
- **Don't** forget `popovertarget` on an `anchor` element — without it the
  panel never opens.

## Content

- Trigger label is a short verb or noun for the panel's purpose ("Filters",
  "Share", "More info").
- Panel copy stays short — it's a lightweight aside, not a page.
