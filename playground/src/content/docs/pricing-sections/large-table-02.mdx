## Add

```sh
npx @ava-ui/apogee add pricing/large-table-02
```

This copies the block to `src/components/apogee/blocks/pricing/` with everything it uses: Button, FeaturedIcon, Section, SectionHeader, Table, Tooltip. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/pricing-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
