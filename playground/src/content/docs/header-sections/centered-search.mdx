## Add

```sh
npx @ava-ui/apogee add header/centered-search
```

This copies the block to `src/components/apogee/blocks/header/` with everything it uses: Input, Section, SectionHeader. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is the page's `h1`; the items below are one level down.
- The search field has a name of its own.
