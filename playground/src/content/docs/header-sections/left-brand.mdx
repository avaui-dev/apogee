## Add

```sh
npx @ava-ui/apogee add header/left-brand
```

This copies the block to `src/components/apogee/blocks/header/` with everything it uses: Section, SectionHeader. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/header-sections#copy-is-props).

## Accessibility

- The heading is the page's `h1`; the items below are one level down.
- Each "Learn more" link names its feature for screen readers.
