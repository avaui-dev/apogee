Three pages for one flow: the user signs up, you email a link and a code, and
they either follow the link or type the code. Each page is a centred
[AuthShell](/docs/sections/auth-shell) with one action and a way back.

```sh
npx @ava-ui/apogee add verification/check-email verification/enter-code verification/success
```
