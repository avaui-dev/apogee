## Add

```sh
npx @ava-ui/apogee add world-map
```

Pulls in Tooltip. The land is drawn from Natural Earth (public domain) as about 1,900 dots in one path, around 18 KB.

## Usage

```astro
---
import WorldMap from '@/components/apogee/WorldMap/WorldMap.astro'
---
<WorldMap pins={[{ label: 'London', detail: '100 Oxford Street', lat: 51.5154, lon: -0.141 }]} />
```

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `pins` | `{ label, lat, lon, detail?, href? }[]` | — | Required. `detail` is the second tooltip line (an address); `href` overrides the full-map link. |
| `label` | `string` | `'Our offices'` | Names the map for screen readers. |
| `region` | `'world' \| 'north-america' \| 'south-america' \| 'europe' \| 'africa' \| 'asia' \| 'oceania'` | `'world'` | The whole world, or one continent: the same dots, cropped to it. |
| `class` | `string` | — | Extra classes on the root, merged last. Width fills; height follows the region's shape (5:2 for the world). |

## States

- **Hover or focus a pin** — a tooltip shows the place and its address.

## Examples

On a contact page: [Map 02](/docs/contact-sections/map-02) and [Vector map 03](/docs/contact-sections/vector-map-03).

## Accessibility

- The dots are decoration and hidden from screen readers; the pins carry the meaning.
- Each pin is a link named by its place and address ("Melbourne, 100 Flinders Street…, opens a map in a new tab"), reachable by Tab, with the tooltip on focus.
- The map is a named group, so a screen reader announces "Our offices" before the pins.
- Pins sit between 84°N and 60°S; places outside that band fall off the edge.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-neutral-faded` | The dots (at half strength) |
| `--background-primary` | Pins |
| `--outline-color-focus` | Pin focus ring |

## Do / Don't

- **Do** pair it with the addresses as text; hide it on phones, where the pins get too small to tap.
- **Don't** use it for more than a dozen places; they crowd.

## Content

- Pin labels are the city; the address goes in `detail`.
