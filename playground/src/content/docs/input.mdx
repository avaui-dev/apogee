## Add

```sh
npx @ava-ui/apogee add input
```

Pulls in `Field` (label/hint/error wiring).

## Usage

```astro
---
import Input from '@/components/apogee/Input/Input.astro'
---
<Input label="Email" type="email" required />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<input>`
attribute (`placeholder`, `name`, `value`, `min`/`max`, `autocomplete`,
`pattern`, `disabled`, …) passes through to the `<input>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated (`apogee-<random>`) | Field id; also used to derive the `aria-describedby` target. |
| `label` | `string` | — | Field label. With `labelPosition="floating"`, doubles as the floating placeholder text. |
| `hint` | `string` | — | Helper text below the field. Hidden when `error` is set. |
| `error` | `string` | — | Error text below the field. Sets `aria-invalid="true"` on the input and `role="alert"` on the message. |
| `type` | `'text' \| 'email' \| 'password' \| 'number' \| 'tel' \| 'url' \| 'search' \| 'date'` | `'text'` | Native input type. |
| `size` | `'small' \| 'medium' \| 'large' \| 'xlarge'` | `'medium'` | Height: 28 / 36 / 48 / 56px. |
| `variant` | `'outline' \| 'faded' \| 'ghost' \| 'headless'` | `'outline'` | The box style: bordered, tinted, bare, or no box at all. |
| `hasError` | `boolean` | `false` | Marks the field invalid (`aria-invalid`, critical border) without an `error` message. |
| `labelPosition` | `'top' \| 'floating'` | `'top'` | `floating` animates the label onto the border on focus / when filled — pure CSS. Ignores a passed `placeholder` (it manages its own). |
| `required` | `boolean` | `false` | Marks the field required (native `required` + a visible `*` next to the label). |
| `class` | `string` | — | Extra classes, merged onto the outer field wrapper. |

## States

- **Hover / focus** — border/token shift on hover; a visible `focus-visible`
  ring on focus.
- **Disabled** — dimmed, `disabled:cursor-not-allowed disabled:opacity-50`.
- **Required** — a `--background-critical`-coloured `*` next to the label.
- **Error** — `--background-critical` border, `aria-invalid="true"`, error message replaces
  the hint.

## Accessibility

- Every control is at least 16px text on viewports below `md`, so focusing a field never zooms the page on a phone; desktop sizes keep their smaller type.

- Real `<label for>` / `<input id>` pairing — always programmatically
  associated, including in `variant="floating"`.
- `aria-describedby` points to the hint or error message id
  (`<id>-hint` / `<id>-error`); error takes priority when both are set.
- `error` sets `aria-invalid="true"` on the input and `role="alert"` on the
  message, so screen readers announce it immediately.
- Focus shows a visible `focus-visible` ring (`--border-primary`).
- `variant="floating"` is pure CSS (`:placeholder-shown` + `peer`) — works
  identically with JS off.
- No JS.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` / `--background-page` / `--foreground-neutral` | Input border, fill, text |
| `--foreground-neutral-faded` | Placeholder, hint text, floating label (idle) |
| `--foreground-critical` | Error border, error text, required `*` |
| `--foreground-primary` | Floating label colour on focus |
| `--border-primary` | Focus ring |

## Do / Don't

- **Do** always pass a `label` — it's the field's accessible name; don't rely
  on `placeholder` alone.
- **Do** use `hint` for guidance before an error occurs, and `error` to
  replace it once validation fails.
- **Don't** pass `placeholder` with `variant="floating"` — it's ignored; the
  label fills that role.
- **Don't** mark a field `required` without validating it — surface real
  errors via `error`, not just the asterisk.

## Content

- Labels are short noun phrases, sentence case, no colon ("Email", not
  "Email:").
- `hint` states the rule before it's broken ("At least 8 characters");
  `error` states what's wrong and how to fix it ("Enter a valid email
  address"), never a generic "Invalid input".
