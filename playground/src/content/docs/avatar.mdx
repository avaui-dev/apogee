## Add

```sh
npx @ava-ui/apogee add avatar
```

Uses `@lucide/astro` (`User`) for the icon shown when neither `src` nor `name`
is set. Ships one scoped JS island (progressive enhancement) that swaps a
broken image for the initials fallback.

## Usage

```astro
---
import Avatar from '@/components/apogee/Avatar/Avatar.astro'
---
<Avatar src="/users/jordan.jpg" name="Jordan Lee" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<span>`
attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | — | Image URL. Omit to always show the initials fallback. |
| `alt` | `string` | `name ?? ''` | Alt text for the image. |
| `name` | `string` | — | Used for the initials fallback (first letter of up to the first two words) and as the fallback's `aria-label`. |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Avatar diameter + text size. |
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning'` | `'neutral'` | Fallback (initials) hue. |
| `variant` | `'solid' \| 'faded'` | `'faded'` | Fallback fill style. |
| `squared` | `boolean` | `false` | Rounded square instead of a circle. |
| `class` | `string` | — | Extra classes, merged last. |

If `src` fails to load, a small JS island removes the `<img>` and shows the
initials fallback instead — it also catches images that had already errored
before the script ran. Without JS, a broken `src` still shows the browser's
broken-image icon; that's inherent to an `<img>` with no fallback path.

## Accessibility

- With `src`: a real `<img>` with `alt` (falls back to `name`, then empty). Pass
  `alt` explicitly for a name-less avatar in a meaningful image context.
- Without `src`, with `name`: the initials fallback gets `role="img"` and
  `aria-label={name}`.
- Without `src` and without `name`: a generic Lucide `User` glyph stands in,
  marked `aria-hidden` as purely decorative — pass `name` (and ideally `src`)
  whenever the avatar needs to identify someone rather than just fill space.

## Tokens

| Token | Used for |
|---|---|
| `--background-neutral` | Initials-fallback background (opaque, so stacked avatars never show through) |
| `--foreground-neutral` | Initials-fallback text |

## Do / Don't

- **Do** pass `name` even when you have `src` — it powers the fallback and the accessible label.
- **Do** use consistent `size` across a single list or group.
- **Don't** omit both `src` and `name` if the avatar needs to identify someone
  — without either, it falls back to a generic decorative icon with no
  accessible label.
- **Don't** put a long name in `alt` when `name` already labels the fallback — keep alt text about the image, not the person's full title.

## Content

- `name` is the person's display name as used elsewhere in the UI — it drives both the initials and the accessible label, so keep it consistent (don't abbreviate here and spell out elsewhere).
