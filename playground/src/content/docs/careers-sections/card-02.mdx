## Add

```sh
npx @ava-ui/apogee add careers/card-02
```

This copies the block to `src/components/apogee/blocks/careers/` with everything it uses: JobCard, Section, SectionHeader, Select. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/careers-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Each position is one link: the title stretches over the card. Its details are a description list (Location, Type, Salary) for screen readers.
- Menus are native selects with a label or an `aria-label`.
