## Add

```sh
npx @ava-ui/apogee add testimonials/social-cards-03-brand
```

This copies the block to `src/components/apogee/blocks/testimonials/` with everything it uses: Avatar, Section, SectionHeader. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
