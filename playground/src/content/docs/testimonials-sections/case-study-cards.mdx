## Add

```sh
npx @ava-ui/apogee add testimonials/case-study-cards
```

This copies the block to `src/components/apogee/blocks/testimonials/` with everything it uses: Button, Carousel, Link, Section, SectionHeader. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The carousel is a named region; its arrows are buttons and it scrolls by swipe or keyboard too.
