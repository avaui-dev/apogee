## Add

```sh
npx @ava-ui/apogee add testimonials/card-brand
```

This copies the block to `src/components/apogee/blocks/testimonials/` with everything it uses: Avatar, Section. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/testimonials-sections#copy-is-props).
