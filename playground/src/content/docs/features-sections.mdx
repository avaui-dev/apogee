Each example is a block: a heading over the features, as a grid of icons,
rows beside a screenshot, a [DeviceFrame](/docs/device-frame) phone or
browser, a [PaymentCard](/docs/payment-card) stack or a
[VideoPlayer](/docs/video-player), or as feature [Tabs](/docs/tabs) that
switch what the screenshot shows.

```sh
npx @ava-ui/apogee add features/simple-icons-02
```

The screenshot blocks show the Apogee dashboard from `/mockups/` (overview,
customers and settings, light and dark); put your own product's screenshots
there.

## Copy is props

Every block in this family takes the same content props (`FeaturesContent` in
`sections/_shared/features.ts`), with its sample copy as the defaults. A block
ignores the props it has no place for, so you can swap one block for another and
keep the copy. The [Features](/docs/sections/features) section takes the same names for the props they share.

- `eyebrow`: The small label above the heading.
- `heading`: The heading.
- `description`: The line under the heading.
- `label`: Landmark name when the block shows no heading.
- `items`: The features. An item's link shows when it has an `href`.
- `linkLabel`: Text of item links without their own `linkLabel`.
- `media`: The main image or screenshot beside or under the features.

- Pass `null` to hide an optional part, such as `description={null}`.
- Some blocks add props of their own; the top of each block's file lists them.
