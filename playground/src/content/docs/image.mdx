## Add

```sh
npx @ava-ui/apogee add image
```

No Apogee dependencies. Wraps Astro's built-in `astro:assets` `Image` — not an
added dependency.

## Usage

```astro
---
import Image from '@/components/apogee/Image/Image.astro'
import hero from '../assets/hero.jpg'
---
<Image src={hero} alt="Team meeting around a table" />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other `astro:assets`
`Image` prop — `width`, `height`, `widths`, `sizes`, `format`, `quality`,
`densities`, … — passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `src` | `ImageMetadata \| string` | — | Required. A local image import (optimised at build) or a remote URL (sized with `inferSize` unless `width`/`height` are given). |
| `alt` | `string` | — | Required. Alt text (`""` for decorative images). |
| `loading` | `'lazy' \| 'eager'` | `'lazy'` | Native lazy-loading. Use `eager` for the page's LCP image. |
| `decoding` | `'async' \| 'sync' \| 'auto'` | `'async'` | Native image decoding hint. |
| `width` / `height` | `number` | — | Intrinsic size; sets the aspect ratio and the largest generated width. |
| `widths` | `number[]` | — | Responsive candidates for `srcset`, e.g. `[480, 800, 1200]`. |
| `sizes` | `string` | — | The `sizes` attribute that picks a candidate; pair it with `widths`. |
| `quality` | `'low' \| 'mid' \| 'high' \| 'max' \| number` | — | Compression of optimised local images. |
| `format` | `'avif' \| 'webp' \| 'png' \| 'jpeg' \| 'svg'` | — | Output format of optimised local images (Astro defaults to `webp`). |
| `fit` | `'cover' \| 'contain'` | — | How the image fills a box sized by `width`/`height` or a class. |
| `radius` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | — | Corner radius token. |
| `outline` | `boolean` | `false` | Inset hairline for images that blend into the page. |
| `class` | `string` | — | Extra classes, merged last (`max-w-full` always, plus `h-auto` unless `fit` is set). |

Slot `fallback`: shown in the image's box when it fails to load (a small island swaps them; without JS the broken image shows its alt text).

## States

- **Loading** — `loading="lazy"` by default; set `eager` on the page's main image.
- **Broken** — with a `fallback` slot, a failed load swaps in the fallback in the same box. Without JS, or without the slot, the browser shows the alt text.

## Accessibility

- `alt` is required — describe the image's content or purpose; pass `alt=""`
  only for purely decorative images.
- `loading="lazy"` (the default) defers offscreen images without JS. Set
  `loading="eager"` on the page's LCP image so it isn't deferred.
- No JS — `astro:assets` processes the image ahead of time; output is a plain
  `<img>`.

## Tokens

None. `Image` has no themeable colour/spacing tokens of its own —
`h-auto max-w-full` keeps it responsive by default; override sizing via
`class`, `width`, or `height`.

## Do / Don't

- **Do** always import a local image (`ImageMetadata`) so `astro:assets` can
  optimize it — don't pass a raw URL string.
- **Do** set `loading="eager"` on the one image that's the page's LCP; leave
  everything else `lazy`.
- **Don't** upscale a small source image via `width`/`height` — `astro:assets`
  will warn or error.
- **Don't** skip `alt` — pass `alt=""` explicitly for decorative images
  rather than omitting it.

## Content

- Alt text describes what's in the image or its purpose (not "image of…"),
  kept short, no ending period unless it's a full sentence.
- Decorative images get `alt=""`, never omitted.
