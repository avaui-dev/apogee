## Add

```sh
npx @ava-ui/apogee add dialog
```

No Apogee dependencies. Uses `@lucide/astro` (`X` close icon). Pair with
`Button` (`command` / `commandfor`) to open and close it.

## Usage

```astro
---
import Dialog from '@/components/apogee/Dialog/Dialog.astro'
import Button from '@/components/apogee/Button/Button.astro'
---
<Button command="show-modal" commandfor="d">Open</Button>
<Dialog id="d" title="Confirm">
  <p>Are you sure?</p>
</Dialog>
```

## Anatomy

- **Header** — auto-generated from `title`; always includes a close button
  (`✕`, `command="close"`).
- **Body** — default slot; the dialog's main content.
- `footer` slot — optional; renders as a bottom action row, only when content
  is passed to it.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute (e.g.
`aria-describedby`) passes through to the root `<dialog>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | — | Required — matches the trigger's `commandfor`. |
| `title` | `string` | — | Renders as the header `<h2>`. |
| `position` | `'center' \| 'start' \| 'end' \| 'top' \| 'bottom' \| 'full-screen'` | `'center'` | Where it sits: centered, docked to a side (`start` / `end` are logical: `end` is the right in LTR and the left in RTL), docked to the top or bottom, or filling the viewport. |
| `dismissOnBackdrop` | `boolean` | `true` | Clicking the backdrop closes the dialog. Set `false` for a decision the user must answer. |
| `class` | `string` | — | Extra classes, merged last. |

## States

- **Open / closed** — the native `[open]` attribute; enter/exit fades and
  slides (`@starting-style`), respects `prefers-reduced-motion`.
- **Backdrop** — fades to 50% black on open (`::backdrop`).

Try each state via the triggers in the Variants preview above.

## Examples

A destructive confirm, with a `danger` footer button:

```astro
<Button color="critical" command="show-modal" commandfor="confirm-delete">Delete account</Button>
<Dialog id="confirm-delete" title="Delete account">
  <p>This can't be undone.</p>
  <Button variant="ghost" color="neutral" command="close" commandfor="confirm-delete" slot="footer">Cancel</Button>
  <Button color="critical" command="close" commandfor="confirm-delete" slot="footer">Delete</Button>
</Dialog>
```

## Accessibility

- Native `<dialog>` opened via `showModal()` (through `command="show-modal"`) —
  the browser traps focus inside it and returns focus to the invoking button on
  close, for free.
- The `title` renders as an `<h2 id="${id}-title">`, wired to `aria-labelledby`
  on the `<dialog>` — when `title` is set, it's announced as the dialog's
  accessible name on open.
- The close button has `aria-label="Close"`.
- **Keyboard** — `Escape` closes it (native `showModal()` behavior); the close
  and footer buttons are reachable with `Tab`.
- **No JS** — opening, closing via the buttons, and `Escape` all still work
  (native). Only the backdrop-click-to-close fallback is unavailable, and only
  in browsers without native `closedby` support.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Dialog border |
| `--overlay` | Backdrop scrim |
| `--background-elevation-raised` / `--foreground-neutral` | Background / default text color |
| `--foreground-neutral` | Title text |
| `--foreground-neutral-faded` / `--background-neutral-faded` | Close button icon / hover background |
| `--border-primary` | Close button focus ring |
| `--radius-lg` | Corner radius |
| `--duration-slow` / `--ease-standard` | Open/close and backdrop transition |

## Do / Don't

- **Do** give every dialog a clear `title` — it's the only heading users get.
- **Do** match `commandfor` to the dialog's `id` exactly — a mismatch silently
  no-ops.
- **Don't** stack multiple modal dialogs — the design isn't built for it.
- **Don't** use `fullscreen` for something that isn't itself a full task (a
  short confirm) — reserve it for immersive flows.

## Content

- Title is a short noun phrase naming the task ("Edit profile", "Delete
  account"), sentence case, no ending punctuation.
- Footer buttons: the affirmative/primary action trailing, a neutral "Cancel"
  leading.
