Each example is a block: a heading over the questions, laid out as a grid
of answers or as an [Accordion](/docs/accordion) that opens one at a time,
with a panel to get in touch.

```sh
npx @ava-ui/apogee add faq/simple-01
```

## Copy is props

Every block in this family takes the same content props (`FAQContent` in
`sections/_shared/faq.ts`), with its sample copy as the defaults. A block
ignores the props it has no place for, so you can swap one block for another and
keep the copy. The [FAQ](/docs/sections/faq) section takes the same names for the props they share.

- `eyebrow`: The small label above the heading.
- `heading`: The heading.
- `description`: Where a block links its description, *asterisks* mark the link text, which points at `primaryAction.href`.
- `label`: Landmark name when there is no heading.
- `items`: Questions.
- `primaryAction`: The contact button (and the description link's target).

- Pass `null` to hide an optional part, such as `description={null}`.
- Some blocks add props of their own; the top of each block's file lists them.
