## Add

```sh
npx @ava-ui/apogee add empty-state
```

No Apogee dependencies. Commonly composed with `Button` in the `actions` slot
and a `@lucide/astro` icon in the `icon` slot.

## Usage

```astro
---
import EmptyState from '@/components/apogee/EmptyState/EmptyState.astro'
---
<EmptyState title="No results" description="Try a different search." />
```

## Anatomy

- **`icon`** slot (optional) — a leading glyph above the title. Sized via
  `[&_svg]:size-8`; pass any SVG (Lucide recommended).
- **Title** — required, always rendered.
- **Description** — optional, rendered under the title when passed.
- **`actions`** slot (optional) — buttons or links, wrapped and centered below the text.

```astro
<EmptyState title="No projects" description="Create your first project to get started.">
  <FolderOpen slot="icon" />
  <Button slot="actions" size="small">New project</Button>
  <Button slot="actions" variant="ghost" color="neutral" size="small">Import</Button>
</EmptyState>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | Required. The primary message. |
| `description` | `string` | — | Optional supporting line, shown under the title. |
| `class` | `string` | — | Extra classes on the root, merged last. |

## Accessibility

Native semantics, no extra ARIA needed — a heading-less block of text and
optional interactive children (icon is `aria-hidden` by convention if decorative;
pass `aria-hidden="true"` on the icon yourself, since the component doesn't add
it). Any `Button`/link placed in `actions` keeps its own keyboard behaviour.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Dashed border around the block |
| `--foreground-neutral` | Title text |
| `--foreground-neutral-faded` | Icon colour and description text |
| `--radius-lg` | Corner radius |

## Do / Don't

- **Do** pair the title with a next step in `actions` when there's one obvious action.
- **Do** keep the description to one sentence explaining why the view is empty.
- **Don't** stack more than two actions — pick the primary path.
- **Don't** use it for error states with a retry — that reads better as an `Alert`.

## Content

- Title is a short noun phrase stating what's missing ("No messages yet",
  "No results found"), not an apology.
- Description (if any) explains why or what to do next, one sentence, no ending period.
- Action label follows Button's content rules (verb + outcome, sentence case).
