## Add

```sh
npx @ava-ui/apogee add hidden
```

No Apogee dependencies.

## Usage

```astro
---
import Hidden from '@/components/apogee/Hidden/Hidden.astro'
---
<Hidden below="lg"><Sidebar /></Hidden>
<Hidden above="lg"><MobileNav /></Hidden>
```

## API

`@composable`. Any other native attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `below` | `'sm' \| 'md' \| 'lg' \| 'xl'` | — | Hidden on viewports narrower than the breakpoint. |
| `above` | `'sm' \| 'md' \| 'lg' \| 'xl'` | — | Hidden on viewports at or wider than the breakpoint. |
| `visually` | `boolean` | `false` | `sr-only`: removed from view, kept for assistive tech. |
| `as` | `'div' \| 'span'` | `'div'` | Tag to render. |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

- Breakpoint hiding uses `display: none`: the content is removed for everyone at that size, including screen readers. Don't hide the only route to a feature.
- `visually` keeps the content in the accessibility tree. Use it for labels that sighted users get from context.

## Tokens

None. Breakpoints come from Tailwind's `--breakpoint-*` scale.

Layout primitive, so no content rules.
