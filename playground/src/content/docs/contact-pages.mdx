Each example is a whole contact page stacked from blocks: a header navigation, an opening block from [Contact sections](/docs/contact-sections) that holds the page's `h1`, then more ways to get in touch, a call to action or a newsletter signup before the footer. Two pages are a form on its own, for a focused contact screen. Adding a page copies its blocks too. The page renders its own header, `<main>` and footer, so give it a layout without a `<main>`.

```sh
npx @ava-ui/apogee add contact/contact-page-01
```

```astro
---
// src/pages/contact.astro
import Layout from '../layouts/Layout.astro'
import Page from '../components/apogee/pages/contact/ContactPage01.astro'
---

<Layout title="Contact">
  <Page />
</Layout>
```
