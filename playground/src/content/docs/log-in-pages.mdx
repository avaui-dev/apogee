Each example is a complete page. The frame comes from the
[AuthShell](/docs/sections/auth-shell) section; the form inside is plain
composition, because it posts to your own auth backend. Add one with
everything it uses, then render it from a route:

```sh
npx @ava-ui/apogee add log-in/split-quote
```

```astro
---
// src/pages/login.astro
import Layout from '../layouts/Layout.astro'
import LogIn from '../components/apogee/pages/log-in/SplitQuote.astro'
---

<Layout title="Log in">
  <LogIn />
</Layout>
```

`npx @ava-ui/apogee list` shows every page.
