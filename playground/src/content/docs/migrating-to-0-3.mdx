0.3 replaces the 0.2 semantic tokens (`--accent`, `--muted`, `--surface` …)
with five hues times seven roles, and gives every component the same prop
vocabulary. Copied components are yours, so the migration touches your repo.

## 1. Update the tokens file

Re-run `npx @ava-ui/apogee init` to refresh `theme.css`, or copy the new
`registry/tokens/theme.css` over yours. If you had hand-edited colours, copy
`scripts/hues.mjs` from the package, change the values, and run
`node node_modules/@ava-ui/apogee/scripts/build-tokens.mjs src/styles/apogee.css ./hues.mjs`
(see [Design tokens](/docs/tokens)).

## 2. Run the codemod

It rewrites utility classes and `var(--…)` references in `.astro`, `.mdx`,
`.md` and `.css` files under `./src` (run it from your project root):

```sh
node node_modules/@ava-ui/apogee/scripts/codemod-0.3.mjs --dry   # list files it would change
node node_modules/@ava-ui/apogee/scripts/codemod-0.3.mjs         # apply
```

Then re-add the components you had copied (`npx @ava-ui/apogee add …`) to pick
up their 0.3 versions, and diff against your local edits.

## 3. Rename props by hand

The vocabulary is the same everywhere: `color` is the hue, `variant` the fill
style, `size` one of `small | medium | large | xlarge`, directions `start | end`.

| Component | 0.2 | 0.3 |
|---|---|---|
| Button | `variant="primary"` | (default) |
| Button | `variant="secondary"` | `variant="outline" color="neutral"` |
| Button | `variant="ghost"` | `variant="ghost" color="neutral"` |
| Button | `variant="danger"` | `color="critical"` |
| Button | `variant="link"` | use `<Link>` |
| Button | `size="icon"` | `iconOnly` |
| Button, Input, Select, Textarea, Combobox, NumberInput, TagInput, PinInput, Checkbox, Radio, Switch, Avatar, AvatarGroup, Spinner, SegmentedControl, ToggleButton | `size="sm" \| "md" \| "lg"` | `size="small" \| "medium" \| "large"` |
| Badge, Tag | `variant="accent"` | `color="primary" variant="solid"` |
| Badge, Tag | `variant="danger"` | `color="critical" variant="solid"` |
| Badge, Tag | `variant="neutral"` | (default) |
| Alert | `variant="info" \| "success" \| "warning" \| "danger"` | `color="primary" \| "positive" \| "warning" \| "critical"` |
| Toaster | `apogeeToast(msg, { variant })` | `apogeeToast(msg, { color })`, same mapping as Alert |
| Input | `variant="floating"` | `labelPosition="floating"` |
| Input, Select, Textarea … | `error` (message) | unchanged; add `hasError` to mark invalid without a message |
| Checkbox, Radio, Switch | — | gained `size`, `hasError` |
| Text | `muted` | `color="neutral-faded"` |
| Text | `size="sm" \| "base" \| "lg"` | `size="small" \| "medium" \| "large"` |
| Eyebrow | `muted` | `color="neutral-faded"` |
| Container | `size` | `width` (`small \| medium \| large \| xlarge \| full`) |
| Section | `space="sm" \| "md" \| "lg" \| "xl"` | `spacing="small" \| "medium" \| "large" \| "xlarge"`; `containerWidth` |
| Dialog | `variant="panel" position="end"` | `position="end"` |
| Dialog | `variant="fullscreen"` | `position="full-screen"` |
| DataGrid column | `align="left" \| "right"` | `align="start" \| "end"` |
| Card | — | gained `raised`, `selected`, `padding` |
| Link | — | gained `color="primary" \| "neutral" \| "inherit"` |
| NavLink | slots `leading` / `trailing` | slots `start` / `end` |
| Stack | `direction="col"` | `direction="column"` (0.4) |
| Progress, Slider, Rating, ProgressIndicator | — | gained `color` |

## 4. Typed props

Every component's `Props` now extends Astro's `HTMLAttributes` for its root
element. Unknown attributes still pass through, but a typo in a known one is a
type error under `astro check`. If you relied on the old `[key: string]: any`
escape hatch for a custom attribute, spread it from an object.

## 5. Check

```sh
npx astro check
npm run build
```

Then open your pages in both themes. The contrast gate covers the tokens;
your own class combinations are yours to look at.
