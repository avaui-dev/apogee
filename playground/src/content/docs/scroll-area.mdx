## Add

```sh
npx @ava-ui/apogee add scroll-area
```

No Apogee dependencies.

## Usage

```astro
---
import ScrollArea from '@/components/apogee/ScrollArea/ScrollArea.astro'
---
<ScrollArea height="20rem" aria-label="Members">
  <ul>…</ul>
</ScrollArea>
```

## API

`@composable`. Any other native attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `'vertical' \| 'horizontal' \| 'both'` | `'vertical'` | Which axes scroll. |
| `height` | `string` | — | Max height, any CSS length. |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

- The container has `tabindex="0"` so keyboard users can focus it and scroll with the arrow keys; it shows the focus ring.
- Give it an `aria-label` (or `aria-labelledby`) when nothing nearby names the region.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Scrollbar thumb |
| `--border-primary` | Focus outline |

Layout primitive, so no content rules.
