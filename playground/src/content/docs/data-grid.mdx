## Add

```sh
npx @ava-ui/apogee add data-grid
```

Pulls in `Checkbox` (row selection). Ships one scoped JS island. Uses
`@lucide/astro` (`ChevronsUpDown`, `ChevronUp`, `ChevronDown` sort icons).

## Usage

```astro
---
import DataGrid from '@/components/apogee/DataGrid/DataGrid.astro'
---
<DataGrid
  columns={[{ key: 'name', label: 'Name' }]}
  rows={[{ name: 'Ada Lovelace' }]}
/>
```

## Anatomy

- **Header row** — one `<th>` per column; `sortable` columns get a button with a
  three-state chevron (unsorted / ascending / descending) and `aria-sort`.
- **Select-all checkbox** — header cell, shown when `selectable`; a `Checkbox`
  wired to an indeterminate state.
- **Body rows** — one `<tr>` per item in `rows`; a checked row's `<tr>` tints
  (`bg-neutral-faded`).
- **Row checkbox** — shown per row when `selectable`; a `Checkbox`.

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root wrapper `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `columns` | `Column[]` | — | Column definitions, in order. |
| `rows` | `Record<string, any>[]` | — | Row data; each row's keys match `columns[].key`. |
| `selectable` | `boolean` | `false` | Adds a checkbox column with an indeterminate select-all. |
| `size` | `'small' \| 'medium'` | `'small'` | Cell padding, matching Table. |
| `striped` | `boolean` | `false` | Alternate row fills. |
| `headerStyle` | `'normal' \| 'caps'` | `'normal'` | Header text: sentence case and semibold, or small caps. |
| `class` | `string` | — | Extra classes on the wrapper, merged last. |

### `Column` shape

| Field | Type | Default | Description |
|---|---|---|---|
| `key` | `string` | — | Key read from each row's data. |
| `label` | `string` | — | Column header text. |
| `sortable` | `boolean` | `false` | Adds a sort button to the header. |
| `align` | `'start' \| 'end' \| 'center'` | `'start'` | Header + cell text alignment (logical, mirrors in RTL). |

## States

- **Unsorted / ascending / descending** — the header chevron swaps to match
  `aria-sort` and the sort button's `data-sort`.
- **Row checked** — the row background tints.
- **Indeterminate select-all** — shown when some, but not all, rows are checked.
- **No JS** — see the JsNote above.

## Accessibility

| Key | Action |
|---|---|
| `Tab` | Moves through the select-all checkbox, sort buttons and row checkboxes. |
| `Enter` `Space` | Sorts by the focused column. |
| `Space` | Toggles the focused checkbox. |

- Semantic `<table>` / `<thead>` / `<tbody>`.
- Each sortable header keeps `aria-sort` (`none` / `ascending` / `descending`) in
  sync with the active sort.
- The select-all `Checkbox` sets the native `indeterminate` property when some
  but not all rows are checked.
- Checkboxes carry `aria-label="Select all"` / `"Select row"`.
- **No JS** — rows render in the order given by `rows`; sort buttons and the
  select-all checkbox render but are inert. Nothing is hidden, so the data
  itself is always readable.

## Do / Don't

- **Do** mark only genuinely sortable columns `sortable` — a chevron implies a
  working sort.
- **Do** keep each column's `key` stable and unique — the client sort matches
  rows by it.
- **Don't** put rich interactive content in a `sortable` cell — sort compares
  the cell's text/number value, not markup.
- **Don't** rely on `selectable` alone for bulk actions — pair it with a visible
  action bar that reacts to the checked rows.

## Content

- Column labels are short nouns, sentence case, no ending punctuation.
- Numeric columns end-align (`align="end"`) and inherit `tabular-nums`
  automatically.
