## Add

```sh
npx @ava-ui/apogee add theme
```

Depends on `utils` (`theme.ts`). The page-level mode (`<html data-theme>`) needs
the head script below; `Theme` only scopes a subtree.

## Usage

```astro
---
import Theme from '@/components/apogee/Theme/Theme.astro'
---
<Theme mode="dark" class="rounded-lg p-6">
  …a dark card on a light page…
</Theme>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the wrapper.

| Prop | Type | Default | Description |
|---|---|---|---|
| `mode` | `'light' \| 'dark' \| 'inverted'` | — | The subtree's colour mode. `inverted` is the opposite of the nearest themed ancestor (or the page). |
| `as` | `string` | `'div'` | Wrapper element. |
| `class` | `string` | — | Extra classes, merged last. The wrapper already sets the page background and text colour. |

## Page mode and the toggle

The page mode lives on `<html data-theme>`. With no attribute the page follows
the system setting. To restore a stored choice, set it before paint with a head
script, then switch it with the helpers in `utils/theme.ts`. [Dark mode](/docs/dark-mode) covers the script and the helpers in full.

```html
<script is:inline>
  const t = localStorage.getItem('apogee-theme')
  if (t) document.documentElement.dataset.theme = t
</script>
```

```ts
import { getTheme, setTheme, toggleTheme } from '@/components/apogee/utils/theme.ts'

toggleTheme()            // light ⇄ dark, persisted, no transition flash
setTheme('dark', { persist: false })
getTheme()               // 'light' | 'dark'
```

`setTheme` adds `apogee-no-transitions` to `<html>` for two frames so the switch
does not tween every colour, re-resolves inverted regions, and dispatches
`apogee:theme-change` (`detail: { mode }`) on `document`.

## States

- **Light / dark** — the two generated token sets; pure CSS, nestable.
- **Inverted** — resolved to one of the two by the island; until then the
  element carries `data-theme="inverted"` and inherits its parent.

## Accessibility

- A themed region keeps every contrast pair of its mode (the tokens are the
  same ones the contrast gate checks).
- Switching the page mode does not move focus or announce anything; pair the
  toggle with a visible label or `aria-label`.

## Tokens

| Token | Used for |
|---|---|
| `--background-page` / `--foreground-neutral` | The wrapper's surface and text |
| every `[data-theme]` token | Re-resolved inside the region |

## Do / Don't

- **Do** use `inverted` for a callout that should stand out from its section
  without knowing the section's mode.
- **Don't** nest more than one `inverted` level for effect; two flips are the
  parent's mode again.
- **Don't** put the page toggle inside an inverted region and expect it to
  read the region's mode: it always reads `<html>`.
- **Don't** rely on the `dark:` utility variant inside a light or inverted
  region nested in a dark one: the variant is ancestor-based, so it still
  applies there. Tokens (`bg-page`, `text-neutral`) follow the region; the
  variant does not.

## Content

- No wording rules of its own. Text inside a themed region follows the rules of the components it holds.
