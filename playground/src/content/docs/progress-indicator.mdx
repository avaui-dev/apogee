## Add

```sh
npx @ava-ui/apogee add progress-indicator
```

No Apogee dependencies.

## Usage

```astro
---
import ProgressIndicator from '@/components/apogee/ProgressIndicator/ProgressIndicator.astro'
---
<ProgressIndicator total={4} current={step} aria-label="Checkout" />
```

Use Progress for a continuous percentage; ProgressIndicator for discrete steps.

## API

`@composable`. Any other native attribute passes through to the root.

| Prop | Type | Default | Description |
|---|---|---|---|
| `total` | `number` | — | Number of steps. |
| `current` | `number` | — | The step in progress, 1-based, clamped to `0..total`. Segments fill up to and including it; it is announced as "Step 2 of 5". |
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning'` | `'primary'` | Hue of the done segments. |
| `aria-label` | `string` | `'Progress'` | Accessible name. |
| `variant` | `'segments' \| 'dots'` | `'segments'` | Segments fill up to the current step; dots mark only the current one, in a window of seven when there are more. |
| `class` | `string` | — | Extra classes on the root, merged last. |

## Accessibility

- One `role="progressbar"` with `aria-valuemin`/`max`/`now` and `aria-valuetext="Step 2 of 5"`.
- The segments are decorative; the name and value carry the meaning.

## Tokens

| Token | Used for |
|---|---|
| `--background-{hue}` | Done segments (`neutral` uses `--background-inverted`) |
| `--background-neutral-faded` | Remaining segments |

## Do / Don't

- **Do** pair it with visible "Step 2 of 5" text when the step count matters.
- **Don't** use it for more than about eight steps. The segments get too thin to read.

## Content

- Set `aria-label` to name the flow ("Setup progress"); the step count is announced for you.
