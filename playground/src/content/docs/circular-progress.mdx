## Add

```sh
npx @ava-ui/apogee add circular-progress
```

No Apogee dependencies. Zero JS.

## Usage

```astro
---
import CircularProgress from '@/components/apogee/CircularProgress/CircularProgress.astro'
---
<CircularProgress value={62} label="Upload progress">62%</CircularProgress>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<div>`
attribute passes through. The default slot sits in the centre (at the bottom
edge for `shape="half"`).

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | `0` | Current value. |
| `min` | `number` | `0` | Lower bound. |
| `max` | `number` | `100` | Upper bound. |
| `label` | `string` | — | Accessible name (`aria-label`); say what is progressing. |
| `size` | `'small' \| 'medium' \| 'large' \| 'xlarge'` | `'medium'` | Ring 32 / 48 / 64 / 96px wide. |
| `thickness` | `'thin' \| 'regular' \| 'thick'` | `'regular'` | Stroke width, relative to the ring. |
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning'` | `'primary'` | Ring hue. |
| `shape` | `'circle' \| 'half'` | `'circle'` | A full ring or the top half (a gauge). |
| `class` | `string` | — | Extra classes, appended last. |

## States

- **Determinate only** — the value is always known; for an unknown wait use [Spinner](/docs/spinner).
- **Animated** — the arc tweens when `value` changes (`--duration-slow`), still under `prefers-reduced-motion` only through your own override; the stroke is a transition, not a loop.

## Accessibility

- `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`; give it a `label`.
- The slot text is visible to everyone; keep it the same number the attributes carry.
- Native semantics, no extra ARIA needed.

## Tokens

| Token | Used for |
|---|---|
| `--background-neutral-faded` | Track |
| `--background-{hue}` | Fill (through the `stroke-{hue}` utility) |
| `--foreground-neutral` | Slot text |
| `--duration-slow` | Arc transition |

## Do / Don't

- **Do** show the number in the slot; a ring alone is hard to read past "about half".
- **Do** use `half` for a gauge (a quota, a score), `circle` for progress.
- **Don't** use it for a step count; that is [Steps](/docs/steps) or [ProgressIndicator](/docs/progress-indicator).
- **Don't** animate from 0 on every render; set the real value server-side.

## Content

- `label` names the thing measured ("Upload progress", "Storage used").
- The slot shows the value in the user's unit (percent, GB, points), short.
