## Add

```sh
npx @ava-ui/apogee add link
```

No Apogee dependencies.

## Usage

```astro
---
import Link from '@/components/apogee/Link/Link.astro'
---
<Link href="/docs">Read the docs</Link>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<a>`
attribute (e.g. `download`, `hreflang`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | — | Required. Link destination. |
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning' \| 'inherit'` | `'primary'` | Text colour; `inherit` takes the surrounding colour. |
| `underline` | `'always' \| 'hover' \| 'none'` | `'always'` | Underline behaviour. |
| `disabled` | `boolean` | `false` | No `href`, `aria-disabled`, dimmed. |
| `external` | `boolean` | `false` | Opens in a new tab (`target="_blank"`) with `rel="noopener noreferrer"`. |
| `class` | `string` | — | Extra classes, merged last. |

## States

- **Hover** — colour shifts to `--background-primary-highlighted`; `underline="hover"` reveals
  its underline.
- **Focus** — a visible `focus-visible` ring (`--border-primary`).

## Accessibility

- Real `<a href>` — full keyboard and assistive-tech support; reachable via
  `Tab`, activates with `Enter`.
- Focus ring always visible on keyboard focus.
- `external` sets `rel="noopener noreferrer"` (the new tab can't access
  `window.opener`) — pair it with a visual cue (e.g. an icon) so users aren't
  surprised it left the site.
- No JS.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-primary` | Link colour |
| `--outline-color-focus` | Focus ring |

## Do / Don't

- **Do** use `Link` for inline, in-sentence navigation; use `Button` with
  `href` for a link that should look like a call-to-action.
- **Do** set `external` (and ideally show an icon) for links that leave the
  site.
- **Don't** rely on colour alone to distinguish a link from surrounding text —
  keep `underline="always"` (the default) for body copy.
- **Don't** use `underline="none"` outside nav/UI chrome where the link is
  already visually distinct (e.g. a menu item).

## Content

- Link text describes the destination ("Read the pricing guide"), never
  "click here" or a bare URL.
- Keep it concise — a few words, not a full sentence.
