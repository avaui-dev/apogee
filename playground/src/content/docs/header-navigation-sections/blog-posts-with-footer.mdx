## Add

```sh
npx @ava-ui/apogee add header-navigation/blog-posts-with-footer
```

This copies the block to `src/components/apogee/blocks/header-navigation/` with everything it uses: Button, FeaturedIcon, Image, Link, NavDropdown, NavLink, Navbar. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/header-navigation-sections#copy-is-props).

## Accessibility

- Each menu is a button with a native popover: Esc or a click outside closes it and focus returns to the button. On phones the menus are rows that expand inside the menu. No JS is needed for either.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
