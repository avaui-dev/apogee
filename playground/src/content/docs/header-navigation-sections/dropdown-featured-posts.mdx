## Add

```sh
npx @ava-ui/apogee add header-navigation/dropdown-featured-posts
```

This copies the block to `src/components/apogee/blocks/header-navigation/` with everything it uses: Badge, Button, FeaturedIcon, Image, Link, NavDropdown, NavLink, Navbar. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- Each menu is a button with a native popover: Esc or a click outside closes it and focus returns to the button. On phones the menus are rows that expand inside the menu. No JS is needed for either.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
