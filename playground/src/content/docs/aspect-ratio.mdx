## Add

```sh
npx @ava-ui/apogee add aspect-ratio
```

No component dependencies.

## Usage

```astro
---
import AspectRatio from '@/components/apogee/AspectRatio/AspectRatio.astro'
---
<AspectRatio ratio="16 / 9">
  <img src="/hero.jpg" alt="Product photo" />
</AspectRatio>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<div>`
attribute passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `ratio` | `string` | `'16 / 9'` | Raw CSS `aspect-ratio` value, e.g. `"16 / 9"`, `"4 / 3"`, `"1 / 1"`. |
| `class` | `string` | — | Extra classes, merged last. |

`ratio` is a free-form CSS value, not an enum — common ratios shown below.

Any content fills the box — `<img>` gets `object-cover`, other children (an
`<iframe>` embed, a `<canvas>`) get `size-full`:

```astro
<AspectRatio ratio="16 / 9">
  <iframe src="https://www.youtube.com/embed/…" title="Demo video" allowfullscreen />
</AspectRatio>
```

## Accessibility

Native semantics, no extra ARIA needed. It's a plain `<div>` sizing a
CSS `aspect-ratio` box — the content inside (an `<img alt>`, an `<iframe title>`)
carries its own accessibility requirements as usual.

## Tokens

No color or spacing tokens — sizing comes from the CSS `aspect-ratio` property
via the `ratio` prop, not from the token system.
