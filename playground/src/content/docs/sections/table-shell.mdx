```sh
npx @ava-ui/apogee add table-shell
```

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `heading`, `description` | `string` | — | content | `heading` required. |
| `searchable`, `searchLabel` | `boolean`, `string` | `false`, `'Search'` | content | A GET form that submits `?q=`. |
| `columns`, `rows`, `selectable` | | | content | Passed to `DataGrid`. |
| `headerStyle` | `'normal' \| 'caps'` | `'normal'` | layout | Passed to `DataGrid`. |
| `currentPage`, `totalPages` | `number` | — | content | Shows `Pagination` when both are set and there is more than one page. |
| `actions` slot | | | content | Toolbar buttons. |
| `layout` | `'simple'` | `'simple'` | layout | |
| `spacing`, `headingLevel`, `id` | | `spacing` is `small` | layout | |
