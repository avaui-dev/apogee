## Add

```sh
npx @ava-ui/apogee add content
```

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | Optional header. |
| `primaryAction` | `{ label, href }` | — | content | Button under the body. |
| `media` | `{ src, alt, width?, height? }` | — | content | For `split`; or the `media` slot. |
| default slot | | | content | The body (paragraphs; `prose` styles any element). |
| `mediaFirst` | `boolean` | `false` | layout | Media on the start side. |
| `label` | `string` | English | content | Landmark name when there is no heading. |
| `layout` | `'split' \| 'prose'` | `'split'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |
