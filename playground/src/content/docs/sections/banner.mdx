## Add

```sh
npx @ava-ui/apogee add banner
```

Pulls in Dismissible, CloseButton, Container and the shared section helpers.

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `heading` | `string` | — | content | Required. The one-line message; it also names the banner region. |
| `description` | `string` | — | content | A quieter second line. Put it in the default slot instead when it holds a link. |
| `layout` | `'floating' \| 'full-width'` | `'floating'` | layout | A card inset from the edges, or a bar with the content in the page container. |
| `background` | `'page' \| 'neutral-faded' \| 'primary-faded' \| 'primary' \| 'inverted'` | `'neutral-faded'` | layout | The fill. On `primary` and `inverted` the text and close button take the on-colour. |
| `align` | `'start' \| 'center'` | `'start'` | layout | `center` centres the text and actions from `md`. |
| `inline` | `boolean` | `false` | layout | Heading and description on one line from `lg`. |
| `fixed` | `boolean` | `false` | layout | `floating` only: pinned to the bottom of the viewport. |
| `dismissible` | `boolean` | `true` | | Show the close button. |
| `closeLabel` | `string` | `'Dismiss'` | content | The close button's name. |
| `id` | `string` | auto | | Root id; the heading gets `{id}-heading`. |

## Slots

| Slot | What goes in it |
|---|---|
| `icon` | A FeaturedIcon or a bare Lucide icon, before the text. |
| default | The description when it holds a link. |
| `actions` | Buttons, an email form, a Countdown. |

## States

- **Dismissed** — the close button removes the banner from the page (the `apogee:dismiss` event fires first and can be cancelled).
- **Not dismissible** — `dismissible={false}` drops the button, for a notice that must stay.

## Accessibility

- The banner is a `region` named by its heading, so it appears in a screen reader's landmark list.
- The close button is a real `<button>` named "Dismiss" (`closeLabel`); it hides without JS.
- On phones the close button sits in the top corner and the text keeps clear of it.

## Tokens

Reads the Section background tokens and on-colours (see [SectionHeader](/docs/section-header)), `--border-neutral` for the edge and `--shadow-raised` for the floating card.

## Do / Don't

- **Do** keep it to one line and one or two actions.
- **Don't** stack several banners; show the most important one.

## Content

- Lead with the news, not the brand: "We've just launched a new feature".
- Put the link on the words that say where it goes.
