
## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | Section header (optional). |
| `items` | `{ value: string, label: string, description?: string }[]` | — | content | Required. Up to four per row. |
| `label` | `string` | English | content | Landmark name when there is no heading. |
| `layout` | `'row' \| 'cards'` | `'row'` | layout | |
| `align` | `'start' \| 'center'` | `'start'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |
