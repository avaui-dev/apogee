## Add

```sh
npx @ava-ui/apogee add pricing
```

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | Optional header. |
| `items` | `{ name, price, annualPrice?, period?, annualPeriod?, description, features: string[], action: { label, href }, featured?, badge? }[]` | — | content | Required. `annualPeriod` replaces `period` while Annual is picked ("year" next to a yearly price). `featured` gets the primary border, button and a "Popular" badge (`badge` overrides the text). |
| `periods` | `{ monthly, annual }` | `Monthly` / `Annual` | content | Labels on the switch. |
| `label` | `string` | English | content | Landmark name when there is no heading. |
| `periodLabel` | `string` | `'Billing period'` | content | Name of the billing switch. |
| `layout` | `'tiers' \| 'tiers-toggle'` | `'tiers'` | layout | |
| `align` | `'start' \| 'center'` | `'center'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |
