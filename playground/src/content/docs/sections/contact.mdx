## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | `heading` required. |
| `details` | `{ icon, label, value, href? }[]` | `[]` | content | Shown in `form-details`. Icons: `mail`, `phone`, `map-pin`. |
| `action`, `method` | `string`, `'get' \| 'post'` | —, `'post'` | content | Passed to the `form`. |
| `submitLabel` | `string` | `'Send message'` | content | |
| `labels` | `{ name?, email?, message? }` | English | content | Field labels. |
| `layout` | `'form-details' \| 'form-only'` | `'form-details'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |

## Accessibility

- Plain HTML form: labelled fields, `required` validation, submits without JS.
- Detail values with `href` are links; icons are decorative.
