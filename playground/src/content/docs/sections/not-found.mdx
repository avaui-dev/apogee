## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `code` | `string` | `'404'` | content | |
| `heading` | `string` | `'Page not found'` | content | |
| `description` | `string` | a default line | content | |
| `primaryAction` | `{ label, href }` | Go home → `/` | content | |
| `secondaryAction` | `{ label, href }` | — | content | |
| `layout` | `'centered'` | `'centered'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | `headingLevel` is `1` | layout | As on every section. |

## Accessibility

- The heading is the page's `h1` by default; the code is a plain paragraph so screen readers hear the heading first.
