## Add

```sh
npx @ava-ui/apogee add cta
```

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | `heading` required. |
| `primaryAction`, `secondaryAction` | `{ label, href }` | — | content | Buttons. |
| `layout` | `'centered' \| 'split'` | `'centered'` | layout | |
| `background` | Section background | `'primary-faded'` | layout | |
| `spacing`, `headingLevel`, `id` | | | layout | As on every section. |
