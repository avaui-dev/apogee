## Add

```sh
npx @ava-ui/apogee add post-header
```

## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow` | `string` | — | content | Category or kicker. |
| `heading` | `string` | — | content | Required. |
| `description` | `string` | — | content | Standfirst. |
| `author` | `{ name, avatar?, role? }` | — | content | |
| `date` | `string` | — | content | Required ISO date. |
| `readingTime` | `string` | — | content | Free text, e.g. "6 min read". |
| `media` | `{ src, alt, width?, height? }` | — | content | Cover image. |
| `locale` | `string` | page locale or `'en'` | content | Date formatting locale. |
| `layout` | `'centered' \| 'split'` | `'centered'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | `headingLevel` is `1` | layout | As on every section. |
