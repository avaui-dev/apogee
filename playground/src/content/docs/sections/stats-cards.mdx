## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `items` | `{ label, value, change?, trend? }[]` | — | content | `Stat` props. |
| `label` | `string` | `'Key metrics'` | content | Landmark name. |
| `layout` | `'row'` | `'row'` | layout | One to four columns by viewport. |
| `spacing` | | `'small'` | layout | |

## Accessibility

- A labelled region ("Key metrics") holding a list; numbers use tabular figures.
