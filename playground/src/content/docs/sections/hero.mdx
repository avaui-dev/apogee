## Add

```sh
npx @ava-ui/apogee add hero
```

Copies to `sections/Hero/` and pulls in Section, SectionHeader, Button, Grid, Image, utils and the shared section helpers (`sections/_shared/`).

## API

`@composable`. Every section wraps `Section` + `Container`, is a labelled landmark, and reads only tokens.

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow` | `string` | — | content | Small label above the heading. |
| `heading` | `string` | — | content | Required. |
| `description` | `string` | — | content | Supporting copy. |
| `primaryAction` | `{ label, href }` | — | content | Solid button. |
| `secondaryAction` | `{ label, href }` | — | content | Outline button. |
| `media` | `{ src, alt, width?, height? }` | — | content | Image beside (`split`) or below (`stacked`) the text. Or use the `media` slot. |
| `layout` | `'centered' \| 'split' \| 'stacked'` | `'centered'` | layout | Composition. |
| `align` | `'start' \| 'center'` | by layout | layout | Text alignment; `centered` defaults to `center`. |
| `background` | `'page' \| 'neutral-faded' \| 'primary-faded' \| 'primary' \| 'inverted'` | `'page'` | layout | Surface token. |
| `spacing` | `'small' \| 'medium' \| 'large'` | `'large'` | layout | Vertical rhythm. |
| `headingLevel` | `1 \| 2 \| 3 \| 4` | `1` | layout | Heading element. |
| `id` | `string` | auto | layout | Section id; the heading gets `{id}-heading`. |

## Accessibility

- A `section` labelled by its heading; `headingLevel` defaults to `1`, so use one Hero per page or lower the level.
- Actions are real links styled as buttons; media gets the `alt` you pass.

## Tokens

Reads the Section background tokens and the on-colours; see [SectionHeader](/docs/section-header).

## Content

- One idea in the heading, one sentence of support, at most two actions.
