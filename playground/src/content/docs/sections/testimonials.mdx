
## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | Optional section header. |
| `items` | `{ quote, name, role?, avatar? }[]` | — | content | Required. `single` shows the first. |
| `label` | `string` | English | content | Landmark name when there is no heading. |
| `layout` | `'single' \| 'grid'` | `'single'` | layout | |
| `align` | `'start' \| 'center'` | `'center'` | layout | |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |

## Accessibility

- Each quote is a `figure` with a `blockquote` and a `figcaption` naming the person; avatars use the name as their label.
