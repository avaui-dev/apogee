## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `eyebrow`, `heading`, `description` | `string` | — | content | Optional section header. |
| `items` | `{ question, answer }[]` | — | content | Required. |
| `label` | `string` | English | content | Landmark name when there is no heading. |
| `layout` | `'accordion' \| 'two-column'` | `'accordion'` | layout | The accordion opens one at a time. |
| `align` | `'start' \| 'center'` | `'start'` | layout | Header alignment. |
| `background`, `spacing`, `headingLevel`, `id` | | | layout | As on every section. |

## Accessibility

- The accordion is native `details` elements with a shared `name`, so keyboard and screen-reader support come from the browser; the two-column layout uses headings one level below the section heading.
