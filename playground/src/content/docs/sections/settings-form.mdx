## API

| Prop | Type | Default | Category | Description |
|---|---|---|---|---|
| `groups` | `{ heading, description?, fields }[]` | — | content | Each field: `kind`, `name`, `label`, `hint?`, `options?` (select), `value?` (`'on'` checks a switch), `required?`, `type?` (input). |
| `action`, `method` | `string`, `'get' \| 'post'` | —, `'post'` | content | Passed to the `form`. |
| `submitLabel` | `string` | `'Save changes'` | content | |
| `cancelLabel` | `string` | — | content | Shows a reset button. |
| `label` | `string` | `'Settings'` | content | Landmark name. |
| `layout` | `'stacked' \| 'two-column'` | `'stacked'` | layout | Two-column puts the group heading beside its fields. |
| `spacing`, `headingLevel`, `id` | | `spacing` is `small` | layout | |

## Accessibility

- Each group is a `fieldset` labelled by its heading; every control has a visible label; the form submits without JS.
