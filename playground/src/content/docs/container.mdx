## Add

```sh
npx @ava-ui/apogee add container
```

No Apogee dependencies.

## Usage

```astro
---
import Container from '@/components/apogee/Container/Container.astro'
---
<Container>
  <p>Page content, centered with side gutters.</p>
</Container>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root element.

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `string` | `'div'` | Element/tag to render (e.g. `'section'`, `'main'`). |
| `width` | `'small' \| 'medium' \| 'large' \| 'xlarge' \| 'full'` | `'large'` | Max width: 48 / 64 / 80 / 90rem, or none. |
| `class` | `string` | — | Extra classes, merged last. |

## States

None — Container is a static layout primitive, no interactive or visual
states.

## Examples

Rendered as a semantic landmark instead of a `<div>`:

```astro
<Container as="main">
  <h1>Page title</h1>
</Container>
```

Nested, for a full-width band with a narrower content column inside:

```astro
<Container width="full" class="bg-neutral-faded">
  <Container width="medium">
    <p>Narrower content inside a full-bleed background.</p>
  </Container>
</Container>
```

## Accessibility

Native semantics, no extra ARIA needed. Pick `as` to match the correct
landmark or semantic element for context (`main`, `section`, `article`, …).

## Tokens

| Token | Used for |
|---|---|
| `--spacing-gutter` (via the `px-gutter` utility) | Fluid side padding, clamps across viewport width |

## Do / Don't + Content

Layout primitive with no content or misuse surface — exempt from Do/Don't and
Content (see the [docs standard](/docs/10-component-docs-standard)).
