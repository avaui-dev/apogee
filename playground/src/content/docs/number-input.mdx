## Add

```sh
npx @ava-ui/apogee add number-input
```

Pulls in `Field`. Ships `@lucide/astro` for the stepper icons. One scoped JS
island (progressive enhancement) for the −/+ buttons.

## Usage

```astro
---
import NumberInput from '@/components/apogee/NumberInput/NumberInput.astro'
---
<NumberInput label="Quantity" name="qty" value={1} min={0} max={99} />
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<input>`
attribute (`name`, `min`, `max`, `step`, `value`, `disabled`, `placeholder`,
`aria-label`, …) passes through to the input itself. `class` is applied to the
outer `Field` wrapper, not the input group.

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | `apogee-<random>` | Field id; auto-generated if omitted. |
| `label` | `string` | — | Field label. |
| `hint` | `string` | — | Helper text below the field (hidden when `error` is set). |
| `error` | `string` | — | Error text; sets `aria-invalid="true"` on the group. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control height. |
| `required` | `boolean` | `false` | Marks the field required (label asterisk + native `required`). |
| `class` | `string` | — | Extra classes on the `Field` wrapper, merged last. |

## Accessibility

- Real `<input type="number">` — typing, native validation, and `↑` / `↓`
  keyboard stepping all work independent of JS.
- The −/+ buttons carry `tabindex="-1"` — deliberately out of the tab order
  (pointer-only); keyboard users get the same result from the native arrow-key
  stepping, so nothing is lost.
- `label`, `hint`, and `error` wire through `Field`: `for`/`id`, and
  `aria-describedby` pointing at the hint or error text (`role="alert"` on the
  error).
- **No JS:** the −/+ buttons are hidden (`no-js:hidden`); the input remains a
  fully working native number field.
- `disabled` propagates to both the `<input>` and the −/+ buttons — they
  disable together, and a disabled button can't fire. The input also gets
  `disabled:cursor-not-allowed`.

## Do / Don't

- **Do** pass `min` / `max` / `step` so native validation matches the stepping
  behaviour.
- **Do** use `size="lg"` for touch-first or prominent quantity pickers.
- **Don't** add `readonly` — it blocks typing for no-JS and keyboard-only users,
  who otherwise get a fully working field.
- **Don't** omit `label` (or `aria-label`) — the field is unlabeled without one.

## Content

- Label is a noun for what's being counted ("Quantity", "Seats"), sentence case.
- Hint states a constraint, not a repeat of the label ("Between 1 and 10").
- Error names the fix ("Enter a value between 1 and 10").
