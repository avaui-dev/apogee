## Add

```sh
npx @ava-ui/apogee add context-menu
```

No Apogee dependencies. Pair with `DropdownItem` for menu entries.

## Usage

```astro
---
import ContextMenu from '@/components/apogee/ContextMenu/ContextMenu.astro'
import DropdownItem from '@/components/apogee/Dropdown/DropdownItem.astro'
---
<ContextMenu>
  <div>Right-click target</div>
  <DropdownItem slot="menu">Copy</DropdownItem>
  <DropdownItem slot="menu">Paste</DropdownItem>
</ContextMenu>
```

## Anatomy

- **Target** — default slot; the element(s) that trigger the menu on right-click.
- **Menu panel** — `slot="menu"`; a `role="menu"` panel positioned at the cursor.
  Fill it with `DropdownItem`s (`role="menuitem"`).

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div>`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `class` | `string` | — | Extra classes on the root wrapper, merged last. |

## States

- **Closed** (default) — the panel is `hidden`.
- **Open** — right-click (or the keyboard context-menu key / Shift+F10) shows the
  panel at the cursor, clamped inside the viewport. Try it in the hero preview
  above.
- **No JS** — the panel stays hidden; the browser's native context menu opens
  instead.

## Events

The panel dispatches `apogee:contextmenu-open` (`detail: { x, y }`) and `apogee:contextmenu-close`, both bubbling.

## Accessibility

- The panel has `role="menu"`; give items `role="menuitem"` (what `DropdownItem`
  renders).
- **Keyboard** — the native context-menu key / Shift+F10 fires the same
  `contextmenu` event as a right-click, so keyboard-only users can still open it.
  On open, focus moves to the first menu item. `ArrowDown` / `ArrowUp` navigate
  between items, wrapping from last to first and back; `Home` / `End` jump to
  the first / last item. Escape closes it.
- **No JS** — the panel stays hidden (`no-js:hidden`); the browser's native
  context menu opens instead, so the actions remain reachable through it.

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Panel border |
| `--background-elevation-raised` | Panel background |
| `--duration-fast` / `--ease-standard` | Panel open fade/scale animation |

## Do / Don't

- **Do** keep items short and task-focused (Cut, Copy, Paste, Delete).
- **Do** offer the same actions somewhere else too (a toolbar, a keyboard
  shortcut) — right-click alone isn't discoverable for every user.
- **Don't** nest anything but menu items (`DropdownItem`) in the panel.
- **Don't** treat it as the only way to reach an action — no-JS visitors fall
  back to the native menu, which won't show your custom entries.

## Content

- Item labels are short verbs (Cut, Copy, Paste, Delete), sentence case, no
  ending punctuation — same rules as `DropdownItem`.
