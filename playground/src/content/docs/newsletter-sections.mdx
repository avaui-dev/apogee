Each example is a block: a [Section](/docs/section) with a
[SectionHeader](/docs/section-header) and a form with an email
[Input](/docs/input) and a submit [Button](/docs/button). The form posts to
the page; point `action` at your list provider.

```sh
npx @ava-ui/apogee add newsletter/simple-centered
```

## Copy is props

Every block in this family takes the same content props (`NewsletterContent` in
`sections/_shared/newsletter.ts`), with its sample copy as the defaults. A block
ignores the props it has no place for, so you can swap one block for another and
keep the copy.

- `eyebrow`: The small label above the heading.
- `heading`: The heading.
- `description`: The line under the heading.
- `submitLabel`: The subscribe button.
- `media`: The screenshot in the phone or browser frame.

- Pass `null` to hide an optional part, such as `description={null}`.
- Some blocks add props of their own; the top of each block's file lists them.
