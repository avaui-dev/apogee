## Add

```sh
npx @ava-ui/apogee add list
```

No Apogee dependencies.

## Usage

```astro
---
import List from '@/components/apogee/List/List.astro'
---
<List>
  <li>First item</li>
  <li>Second item</li>
</List>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<ul>` /
`<ol>` attribute passes through (`...rest`).

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `'ul' \| 'ol'` | `'ul'` | Element tag — unordered or ordered list. |
| `marker` | `'default' \| 'none'` | `'default'` | `none` drops the marker and its start indent. |
| `class` | `string` | — | Extra classes, merged last. |

## Accessibility

Native semantics, no extra ARIA needed. `<ul>` / `<ol>` with real `<li>`
children already gives assistive tech the list role, item count, and position.

## Tokens

| Token | Used for |
|---|---|
| `--foreground-neutral-faded` | Marker (bullet / number) colour |

## Do / Don't

- **Do** use List for a set of related items where a marker or order carries
  meaning.
- **Do** pass `marker="none"` when nesting a List inside a layout that
  supplies its own bullets or icons.
- **Don't** use List for layout rows or navigation — use `Stack` or `Navbar`.
- **Don't** put non-`<li>` children directly in the slot — the marker and
  indent styling target `<li>`.

## Content

- Keep items short — sentence case, no ending period unless the item is a
  full sentence.
- Keep phrasing parallel across items (all start with the same part of
  speech).
