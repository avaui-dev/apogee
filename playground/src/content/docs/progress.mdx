## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through to the root `<div role="progressbar">`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | `0` | Current value, `0`–`max`. Ignored visually when `indeterminate`. |
| `min` | `number` | `0` | Lower bound. |
| `max` | `number` | `100` | Maximum value. |
| `label` | `string` | — | Accessible label (`aria-label`) — there's no visible text otherwise. |
| `indeterminate` | `boolean` | `false` | Shows a sliding animated fill instead of a value-based width; drops `aria-valuemin` / `aria-valuemax` / `aria-valuenow`. |
| `size` | `'small' \| 'medium'` | `'medium'` | Bar thickness: 4 / 8px. |
| `color` | `'primary' \| 'neutral' \| 'critical' \| 'positive' \| 'warning'` | `'primary'` | Hue of the fill. |
| `labelPosition` | `'none' \| 'end' \| 'bottom' \| 'floating'` | `'none'` | Where the value text shows: after the bar, under it, or in a chip that floats above the fill. |
| `format` | `string` | `'{percent}%'` | Value text template; `{value}`, `{percent}` and `{max}` are replaced. |
| `class` | `string` | — | Extra classes on the root wrapper, merged last. |

## Accessibility

- `role="progressbar"` with `aria-valuemin` / `aria-valuemax` / `aria-valuenow`;
  all three are omitted when `indeterminate`, matching the ARIA spec for an
  indeterminate progress meter.
- `label` sets `aria-label` — always pass one; the bar has no visible text.
- The indeterminate slide respects `prefers-reduced-motion`: its 1.2s loop
  slows to 3s. The determinate fill's width transition has no separate
  reduced-motion guard.

| Token | Used for |
|---|---|
| `--background-neutral-faded` | Track background |
| `--background-primary` | Fill |
| `--background-inverted` / `--on-inverted` | Floating value chip |
| `--duration-slow` | Determinate fill transition duration |
| `--ease-standard` | Transition / animation easing |

## Do / Don't

- **Do** always pass `label` — the bar has no visible text of its own.
- **Do** use `indeterminate` only when a percentage genuinely can't be computed;
  switch to determinate the moment you can.
- **Don't** write the value into the track yourself; use `labelPosition`, which keeps the text out of the fill.
- **Don't** animate `value` faster than users can perceive as real progress
  rather than decoration.

## Content

- `label` states what's progressing ("Uploading…", "Step 2 of 4"), not the
  percentage — the number is already conveyed through ARIA.
