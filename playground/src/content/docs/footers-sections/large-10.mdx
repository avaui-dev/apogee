## Add

```sh
npx @ava-ui/apogee add footers/large-10
```

This copies the block to `src/components/apogee/blocks/footers/` with everything it uses: Badge, Button, FeaturedIcon, Heading, Link, Section. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/footers-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- Each "Learn more" link names its feature for screen readers.
- The icon links are named (Email, Blog feed, Community…); the icons themselves are hidden.
- The block is the page's `<footer>` landmark; each link column is a `<nav>` named after its heading.
