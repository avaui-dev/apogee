## Add

```sh
npx @ava-ui/apogee add footers/large-03
```

This copies the block to `src/components/apogee/blocks/footers/` with everything it uses: Badge, Button, FeaturedIcon, Link, Section. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/footers-sections#copy-is-props).

## Accessibility

- The block is the page's `<footer>` landmark; each link column is a `<nav>` named after its heading.
