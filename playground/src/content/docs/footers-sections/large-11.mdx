## Add

```sh
npx @ava-ui/apogee add footers/large-11
```

This copies the block to `src/components/apogee/blocks/footers/` with everything it uses: Button, FeaturedIcon, Heading, Link, Section. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The icon links are named (Email, Blog feed, Community…); the icons themselves are hidden.
- The block is the page's `<footer>` landmark; each link column is a `<nav>` named after its heading.
