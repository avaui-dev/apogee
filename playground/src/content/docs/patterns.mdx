## Filter bar

Search, a period switch and a Filters popover holding a GET form: the filters
submit with zero JS and the server renders the filtered page. Clear is a link
to the unfiltered URL, not a reset button: a reset would restore the values
the server just rendered. The badge on
the trigger counts the applied filters.
