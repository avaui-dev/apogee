One flow, four pages: the user asks for a reset, you email a link, they set a
new password, and they are done. Each page is a centred
[AuthShell](/docs/sections/auth-shell) with one action and a way back; the
sidebar version shows every step at once.

```sh
npx @ava-ui/apogee add forgot-password/forgot-password forgot-password/check-email forgot-password/set-new-password forgot-password/success
```
