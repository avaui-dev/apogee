## Add

```sh
npx @ava-ui/apogee add button
```

Pulls in `Spinner` (loading state). Bring `@lucide/astro` for icon children.

## Usage

```astro
---
import Button from '@/components/apogee/Button/Button.astro'
---
<Button variant="primary">Get started</Button>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other native
`<button>` / `<a>` attribute (e.g. `aria-label`, `name`, `form`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'link'` | `'primary'` | Visual style. `link` renders as plain underlined text. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon'` | `'md'` | Control size. `icon` is square, icon-only. |
| `href` | `string` | — | Renders an `<a>` instead of a `<button>`. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Button type (ignored when `href` is set). |
| `disabled` | `boolean` | `false` | Disables the button (native on `<button>`; drops `href` + sets `aria-disabled` on a link). |
| `loading` | `boolean` | `false` | Shows a `Spinner`, blocks interaction, sets `aria-busy`. |
| `class` | `string` | — | Extra classes, merged last. |

## States

- **Hover / active** — token-driven background shift; a subtle press scale
  (`active:scale-95`, motion-reduce safe).
- **Focus** — a visible `focus-visible` ring (`--ring`).
- **Disabled** — dimmed, not focusable-as-action.
- **Loading** — a `Spinner` replaces the leading content; the label stays and
  `aria-busy="true"` is set.

## Accessibility

- Real `<button>` / `<a>` — full keyboard + AT support for free. `href` →
  anchor (navigates); no `href` → button (acts). Never a `<div>`.
- Focus ring is always visible on keyboard focus.
- `size="icon"` has no visible text — always pass an `aria-label`.
- `loading` sets `aria-busy`; a disabled `<button>` uses the native `disabled`
  attribute, a disabled link drops its `href` and sets `aria-disabled`.
- The press animation respects `prefers-reduced-motion`.

## Tokens

| Token | Used for |
|---|---|
| `--accent` / `--accent-hover` / `--accent-foreground` | Primary background / hover / label |
| `--border` / `--background` / `--muted` | Secondary + ghost surface, border, hover |
| `--danger` / `--danger-hover` / `--danger-foreground` | Danger variant |
| `--ring` | Focus ring |
| `--radius-md` | Corner radius |

## Do / Don't

- **Do** use one primary button per view — the main action.
- **Don't** use a Button for navigation — use `href` (renders a link) or the
  `Link` component.
- **Don't** hard-code colours — restyle via tokens.

## Content

- Label leads with a verb and names the outcome ("Save changes"), sentence case,
  1–3 words, no ending period. Icon-only (`size="icon"`) needs an `aria-label`.
