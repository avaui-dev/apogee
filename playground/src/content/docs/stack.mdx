## Add

```sh
npx @ava-ui/apogee add stack
```

No Apogee component dependencies.

## Usage

```astro
---
import Stack from '@/components/apogee/Stack/Stack.astro'
---
<Stack gap={2}>
  <p>First</p>
  <p>Second</p>
</Stack>
```

## API

`@composable` — exposed to Content Editors in AVA. Any other attribute passes
through onto the rendered tag.

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `string` | `'div'` | Element/tag to render. |
| `direction` | `'column' \| 'row' \| 'column-reverse' \| 'row-reverse'`, responsive | `'column'` | Stack axis. |
| `gap` | `0 … 6 \| 8 \| 10 \| 12 \| 16`, responsive | `4` | Gap between children (Tailwind's numeric spacing scale). |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'`, responsive | — | Cross-axis alignment (`items-*`). |
| `justify` | `'start' \| 'center' \| 'end' \| 'between' \| 'around' \| 'evenly'`, responsive | — | Main-axis distribution (`justify-*`). |
| `wrap` | `boolean`, responsive | — | Allows children to wrap (`flex-wrap`). |
| `class` | `string` | — | Extra classes, merged last. |

## Responsive values

## States

Not applicable — Stack is a static layout primitive with no interactive states.

## Examples

Polymorphic tag for correct semantics:

```astro
<Stack as="ul" gap={1}>
  <li>First</li>
  <li>Second</li>
  <li>Third</li>
</Stack>
```

Nested Stacks — a vertical form with a right-aligned button row:

```astro
<Stack gap={4}>
  <input class="rounded-md border border-neutral px-3 py-2" placeholder="Email" />
  <Stack direction="row" gap={2} justify="end">
    <button class="rounded-md border border-neutral px-3 py-2 text-sm">Cancel</button>
    <button class="rounded-md bg-primary px-3 py-2 text-sm text-on-primary">Save</button>
  </Stack>
</Stack>
```

## Accessibility

Native semantics, no extra ARIA needed. Stack renders a plain container
(`<div>` by default, or your chosen `as` tag) with no interactive behavior of
its own — pick an `as` value with the right semantics for your content (`ul`,
`nav`, `section`, …); Stack adds none.

## Tokens

Stack reads no Apogee design tokens directly — `gap` maps to Tailwind's
built-in numeric spacing scale (`gap-0`…`gap-12`), not a themeable custom
property.

## Do / Don't

Layout primitive — no content or misuse surface beyond picking the right
props; the usual Do/Don't guidance doesn't apply.

## Content

Not applicable — Stack renders no text of its own.
