## Add

```sh
npx @ava-ui/apogee add content/alternative-02
```

This copies the block to `src/components/apogee/blocks/content/` with everything it uses: Avatar, Badge, Carousel, Heading, Image, Prose, Section. Replace the sample data at the top of the file with yours, or use **Copy code** above to paste it instead.

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The carousel is a named region; its arrows are buttons and it scrolls by swipe or keyboard too.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
