## Add

```sh
npx @ava-ui/apogee add card
```

No Apogee dependencies. Commonly composed with `Heading`, `Text`, `Button`, and `Image`.

## Usage

```astro
---
import Card from '@/components/apogee/Card/Card.astro'
import Heading from '@/components/apogee/Heading/Heading.astro'
---
<Card>
  <Heading as="h3">Card title</Heading>
  <p>Body copy.</p>
</Card>
```

## Anatomy

Card is a single component with named slots for its regions, not a
Card.Header/Card.Body family:

- **Root** — the `<a>` (when `href` is set) or `<div>` surface: border, radius,
  background. Any content you pass goes directly inside its padded body, in
  the default slot.
- **`slot="media"`** (optional) — renders flush at the top, above the body,
  clipped to a 16:9 (`aspect-video`) box; with `mediaPosition="start"` it
  becomes a fixed-width column beside the body from `sm`. Meant for an
  `<img>` — the slot content is sized to fill it (`size-full object-cover`).
- **`slot="header"`** (optional) — a bordered row above the body, stacked on
  phones and a row from `md`, for a title, a badge, actions.
- **`slot="footer"`** (optional) — a bordered row below the body for links or
  buttons; put `class="ms-auto"` on the group that should sit at the end.

## API

`@composable` — exposed to Content Editors in AVA. Any other native `<a>` /
`<div>` attribute (e.g. `target`, `rel`, `aria-label`) passes through.

| Prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | — | Renders the card as an `<a>` and makes the whole surface a link (hover/focus states apply). Omit for a static `<div>`. |
| `as` | `'div' \| 'article' \| 'section' \| 'li' \| 'button'` | `'div'` | Tag to render; `button` makes the whole card a button (ignored when `href` is set). |
| `raised` | `boolean` | `false` | Adds the raised shadow. |
| `selected` | `boolean` | `false` | Primary border, for a chosen card in a set. |
| `padding` | `'none' \| 'small' \| 'medium' \| 'large'` | `'medium'` | Body padding; header and footer rows use the same horizontal step with a shorter vertical one. With `none` (a flush table or image) the regions keep the medium step. |
| `mediaPosition` | `'top' \| 'start'` | `'top'` | Where the `media` slot sits: above the body, or a 15rem column beside it from `sm`. |
| `class` | `string` | — | Extra classes, merged last. |

## States

Interactive states only apply when `href` is set (the whole card is a link):

- **Hover** — background shifts to `--background-neutral-faded-highlighted`.
- **Focus** — a visible `focus-visible` ring (`--outline-color-focus`).
- **Static** (no `href`) — no hover/focus treatment; it's a plain container.

## Accessibility

- With `href`, the whole surface is a real `<a>` — keyboard-focusable,
  `Enter` navigates, no `div` click-handler faked.
- Without `href`, it's a plain `<div>` — don't add a click handler to fake
  navigation; use `href` instead so it stays keyboard-operable.
- If a linked card also contains its own interactive children (a Button),
  avoid nesting a second link/button *inside* an `href` card — nested
  interactive controls are invalid HTML and confuse both mouse and keyboard
  users. Keep linked cards content-only, or keep the card static and put the
  single action inside.
- `media` images need real `alt` text (or `alt=""` if purely decorative).

## Tokens

| Token | Used for |
|---|---|
| `--border-neutral` | Card outline |
| `--background-elevation-raised` / `--foreground-neutral` | Card background / default text color |
| `--background-neutral-faded-highlighted` | Hover background (linked cards only) |
| `--outline-color-focus` | Focus ring (linked cards only) |
| `--border-neutral` | Header and footer rules |
| `--radius-lg` | Corner radius |

## Do / Don't

- **Do** use `href` when the whole card should be one click target — don't bury the only action in a nested link.
- **Do** keep card content short — a heading, a line or two, maybe one action.
- **Don't** nest another link or button inside an `href` card.
- **Don't** mix unrelated content types in a grid of cards — keep each card's shape consistent within a set.

## Content

- Title is a short noun phrase (`Heading`, 2–6 words), not a full sentence.
- Supporting text is one to two lines — truncate or link to "Read more" rather than letting a card grow tall in a grid.
