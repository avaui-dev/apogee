## Add

```sh
npx @ava-ui/apogee add cta/split-image-quote-02
```

This copies the block to `src/components/apogee/blocks/cta/` with everything it uses: Button, Carousel, Image, Rating, Section, SectionHeader. Every piece of copy is a prop, with the sample copy as its default. Pass yours, or `null` to hide a part; see [copy is props](/docs/cta-sections#copy-is-props).

## Accessibility

- The heading is an `h2` by default, so the block slots into a page under its `h1`; item titles are one level down.
- The carousel is a named region; its arrows are buttons and it scrolls by swipe or keyboard too.
- Photos that only decorate have an empty `alt`; give yours one when it carries meaning.
